## 结论（一句话，可直接被下游引用）

拿不到自有搜索词导出时，用竞品流量词词频做需求分布代理（DDD 降级口径）：场景/主题占比排变体优先级与档期，功能词占比定标题主词，买家主动标注的特征词占比定第一转化杠杆，差评主诉+词频双证据定五点配比；低样本全部标 case_default，无证据写 unknown。

## 机制 / 原因

词频≈客户用脚投票的需求分布：竞品已上架的主题与规格是付费验证过的需求切片，占比排序把「先做哪个变体、五点先喊什么」从主观判断变成分布驱动。代理必然偏：词频只来自少数可反查 ASIN，主题分布偏向竞品已上架的方向，会低估未开发主题——所以只用于排序，不当精确份额。

## 操作 / 参数

1. 降级口径声明：无蜂爪/自有导出时用竞品流量词词频替代（案例 160 词次、4 个可反查 ASIN），样本量写进每张占比表。
2. 四张占比表：①场景主题占比 → 变体 V1/V2 优先级与窗口（案例 fall 13.1% 主推、halloween 11.2% 次推）；②功能词根占比 → 标题核心词（outfit 65%）；③产品特征占比 → 转化杠杆（带尺码搜索 18.1%，与差评最大痛点「尺码不合」互证）；④人群动机占比 → 五点配比指令：差评主诉+词频双证据的卖点才排前两位。
3. 他人品牌词有真实搜索量（案例 3 词合计约 1.5 万/月）= 头部心智占位 + IP 红线证据：否词 + brand_review，禁止投放埋词，只以通用词+差异化卖点另立心智。
4. 词库计划外发现单独立「机会警报」：高量高 CVR 词群（案例 back-to-school 43,231/月 CVR 11.2%、桌面鹅词群 >14 万/月且 CVR 高于主线）给出决策点与窗口，错过等明年；独立细分不混进主链接变体。
5. 最强反方必写：竞品词频≠全市场需求、SIF 24h 点击 CVR 系统性低于账户真实 CVR（ACOS 预演偏保守）、载体裸词可能被误判——投放后用搜索词报告回填验证。

## 适用 / 不适用

- 适用：有词库/反查工具但无自有店铺搜索词报告的新品期（从0到1、精铺）。
- 不适用：有自己账户搜索词报告时直接用一手数据；词频占比不替代热卖原因十查需求闸门（KC-0009）；挖属性词根走 KC-0091 词根蓝海值法，本卡管占比→变体/卖点排序。
- 站点/类目差异：主题组织型类目（节日/图案）占比信号最强；标品规格占比同样适用。

## 证据

Porch Goose 装扮线 06E：fall 13.1% 定 V1、no-DIY 差评 26/41 与尺码词 18.1% 双证据排五点前两位、品牌词 1.5 万/月进 IP 黑名单、两个计划外机会警报（SRC-1316，2026-09-01）。

## 反方 / 已知冲突

单案例；160 词次低样本，占比只能排序不能当精确份额；按当前竞品结构外推季节占比会低估峰月。验证：首批广告跑 2 周后用搜索词报告回填验证场景占比与载体词判定；账户真实 CVR 回写重算 ACOS 预演；变体上线后核对词频占比与实际销量占比的偏差，偏差即代理口径的修正量。
