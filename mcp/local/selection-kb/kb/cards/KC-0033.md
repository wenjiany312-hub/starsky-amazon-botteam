## 结论（一句话，可直接被下游引用）

类目方向不能只刷 Best Seller / 新品榜：从已定大类把子节点逐个点开、从头看到尾，把平时想不到的专业产品记进候选，再回到四失衡。

## 机制 / 原因

KC-0007 给三路展开（浏览 / 翻译搜 / 产品查询）。榜单只露出已经热的形态；专业、冷门、看不懂的产品往往埋在子节点中后段。课上口径：这是笨但有效的方法，用来训练三要素识别，不是用来替代扫描。

## 操作 / 参数

1. 先定边界（价格带 / 认证 / 能不能做），再选熟悉或感兴趣的大类。
2. 用类目表或前台节点，从大类下的子类目一个个点进去；每个子节点先整页看完，再进下一节点。
3. 记录「平时想不到」的专业品，不要求当场立项。
4. 展开名单仍要过四失衡与十查；类目看完 ≠ 该节点都能做。

## 适用 / 不适用

- 适用：已有类目/主题、走垂直或从0到1的类目入口。
- 不适用：完全无方向（先走大盘 KC-0032）；只要节日表。
- 站点/类目差异：节点树因站点而异，必须写 marketplace。
