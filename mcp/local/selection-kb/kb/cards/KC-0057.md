## 结论（一句话，可直接被下游引用）

1688 上带竞品品牌词/近似视觉的「仿品牌现货」（页写「私模专利、跨境爆款」话术）对新卖家是双杀：百件档采购价 ¥65-66 已占主销价 $17.99 的 54%，FBA 后毛利 -8%~1.3%；叠加品牌仿冒、H 图案、橙色同款等 IP 风险——只能反向参考结构，不能作为开发主线，判放弃。

## 机制 / 原因

仿品牌线是分销/炒货价不是源头成本，价格天然高；而其卖点（品牌词流量、专利结构暗示）恰恰是平台打击对象。两条成本（采购贵 + 违规下架）叠加，商业模型不成立。案例结论「最多用于反向理解结构和市场热度，不能作为 Listing、图片、包装参考模板」。

## 操作 / 参数

1. 看到「适用大疆/STARTIRC/品牌词 + 源头工厂 + 私模专利」组合话术 → 标记为疑似仿品牌线。
2. 只做结构/热度情报，不入主供应商评分池（KC-0054 只收 A/B 正规池）。
3. 页面宣称「私模专利」但无专利号 → 不采信、不写入 Listing。
4. 品牌兼容表达（适用 XX）与品牌词混用是平台误判高危，Listing 禁用。

## 适用 / 不适用

- 适用：1688 选货时的货源合法性初筛；解释「为什么同款更贵也不能做」。
- 不适用：正规品牌授权分销（有授权文件另议）；对自有专利产品无意义。

## 证据

仿品线价格对比与粗算毛利表（SRC-0455 §10.3）；四条不纳入评分原因（SRC-0455 §10.4）。

## 反方 / 已知冲突

暂无。与 KC-0011（品牌词带量复制不来）、KC-0026（大牌平替不能做）同向：流量与合规都拿不到。
