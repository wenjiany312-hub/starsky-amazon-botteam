## 结论（一句话，可直接被下游引用）

广告效率必须先锁相似产品，再对 **3–5 个自然位靠前** 的相似竞品分别算月销÷广告词；禁止拿大盘平均或异形态头部当样本。广告词极少且销量高 = 自然主导，优先。

## 机制 / 原因

KC-0015 给公式和 >80% 否决。分母错了，效率再漂亮也是假市场：换一个词就是另一局，头部异形态不算相似产品（KC-0013）。多源同一指标差 >20% 先对口径，不合并。

## 操作 / 参数

1. 切到可判定的核心词，只在「相关且竞争」里锁相似产品。
2. 取自然位靠前的 3–5 个，记录全部流量词 / 自然词 / 广告词 / 月销。
3. 逐个算效率与广告词占比；标友好（观测带 6–17，KC-0015）/ 烧广告硬顶 / 自然主导。
4. 与评论区间交叉（KC-0016）。本步仍不做立项终裁。

## 适用 / 不适用

- 适用：难度判定、十查烧广告项的取数。
- 不适用：用全站广告词数或未切词的大盘当样本。
- 站点/类目差异：报告必须写数据源；「广告词」定义因工具而异。
