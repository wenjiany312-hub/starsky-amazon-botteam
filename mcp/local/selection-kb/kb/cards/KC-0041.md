## 结论（一句话，可直接被下游引用）

货源倒推（KC-0025）过闸前必须填完供应检查项：公司类型、MOQ、交期、认证、打样/试用、质量与交付记录。缺项标「待供应商确认」，不编报价，也不用「有工厂」代替检查。

## 机制 / 原因

有货源只说明能问到人。沟通表（C 级，大会资料）把「痛点反馈 / 迭代 / 实物试用 / 交期 / 包装」列为必聊；考核表用质量、成本、交付、服务、技术五维。B 级供应商评估要求字段缺失不得自行补造。两套表的打分细则是社群经验，不上升为平台规则。

## 操作 / 参数

1. 先锁可生产、可认证、可算到岸（KC-0025）。
2. 按 SRC-0050 必填字段抽 1688 页或用户报价；空格写待确认。
3. 沟通至少覆盖：已出货痛点、能否拿样试用、交期、包装改进。
4. 考核至少留下质量/交付/成本三格，再回市场走十查与双法。数据不够评分 → 只出补充清单，不强行立项。

## 适用 / 不适用

- 适用：已有 1688/工厂、走货源倒推。
- 不适用：用考核高分跳过需求验证。
- 站点/类目差异：认证项随类目变（食品接触、儿童、电子），缺则待确认。

## 证据

alibaba-supplier-evaluation（SRC-0050）；供应商沟通表（SRC-0322）；供应商考核表（SRC-0323）。

## 反方 / 已知冲突

考核表分数带是 C 级社群口径，与 SRC-0050 七维权重并列，不裁决。
