## 结论（一句话，可直接被下游引用）

类目抓不到真实 Top20 销量时（前台风控/新类目/工具缺数），难度双法没分子可用，改用**三代理加权**：头部集中度代理（头部评论量占样本比重）×0.4 + 评论壁垒（样本中位评论数折算）×0.35 + 价格战系数（样本中低于建议价的比例）×0.25，结果 0.67/1.00 判「困难」——不是不能做，是必须有结构+证据差异才进场（推论，2026-06-15）。

## 机制 / 原因

难度双法（KC-0014 评论区间法 / KC-0015 广告效率法）都依赖真实销量做分子；数据缺失时若强行填造搜索量/销量，难度就变成假精度。三代理全部来自**可核验的公开样本**：竞品评论数、价格、评分——它们与销量的相关性弱但与「壁垒强度」相关性稳定，够用来回答「这家难不难」，不够用来回答「市场多大」，后者必须标缺口留待补数。

## 操作 / 参数

1. 采样：直接竞品 3 个 + 价格带观察样本若干（案例 3 直接 + 观察带 3 档），记录评论数/评分/售价/上架年限。
2. 三代理算法（2026-06-15 案例口径）：头部集中 = 头部评论量相对样本离散度（0.65）；评论壁垒 = 样本中位评论量级折算（588 条中位 → 0.70）；价格战 = 低于建议售价样本占比（2/3 → 0.67）。
3. 加权与判定：0.4/0.35/0.25 加权（案例 = 0.67，困难带）；>0.8 建议放弃或明年验证，0.6-0.8 必须带差异化结构进场，<0.6 正常推进。
4. 缺口标注：销量、市场份额、搜索量一律标「缺数待补」，禁造精确值；后续用工具补 ABA/SIF 后切换回 KC-0014 双法复算。
5. 结论输出：难度值只与「进场姿态」挂钩（普通款否 / 升级款条件进），不直接等于 go/abort。

## 如何验证

- 案例复算：狗耳罩（2026-06-15）0.65/0.70/0.67 → 0.67 困难，结论「Happy Hoodie 17,695 评论壁垒高、需可调节结构+实测证据差异化」，与逐 ASIN 人工判读一致。
- 交叉验证：同品类后续补到 ABA 数据后，用 KC-0014 重算，比较代理难度与真实难度的方向是否一致。

## 适用 / 不适用

- 适用：新类目/被风控类目的快速难度估计、深研前期的 go-no-go 姿态选择。
- 不适用：替代正式难度双法（拿到销量数据必须复算）；样本 <3 个时不可用。
- 站点/类目差异：权重为单案例推定，换类目先做 ±5% 敏感性检查。

## 证据

狗狗安抚耳罩市场调研：三代理采样、公式与 0.67 判定、结论与破局点（SRC-1127 §3/§6.1/§6.3）。

## 反方 / 已知冲突

权重 0.4/0.35/0.25 为单案例经验值，未经多类目回归——这是本卡最大弱点，复用前先做敏感性测试；与 KC-0014 不冲突（本卡是缺数时的降级方案，不是替代）。
