## 结论（一句话，可直接被下游引用）

类目差异先看硬门槛，再看找法：宠物不能当一个类目一刀切（食品/保健/杀虫黄红灯，物理工具绿灯）；家居收纳优先打开子节点整层看，不要只盯一个种子词。

## 机制 / 原因

同一「宠物」下，拾便袋和跳蚤药的审批、FDA/EPA、侵权词完全不同。SRC-0324 把宠物拆成绿灯（清洁工具、碗、服饰）和黄灯（食品、维生素、杀虫、带电）。家居收纳在沙龙里的找法是类目节点下钻（与 KC-0033 同构）。服装等类目本卡不编差异，连做两类目后再补。

## 操作 / 参数

1. 锁类目前先对类目家族打灯：宠物食品/保健/杀虫 → 默认放弃或专家评估；物理工具/家居收纳 → 可进十查。
2. 宠物标题回避 Purina、KONG、FURminator 等品牌词（SRC-0324 名单，经验口径）。
3. 家居收纳：前台子节点从头看到尾，再回四失衡。
4. 含杀菌声明的酶清洁剂按 EPA 再核，不当普通清洁。

## 适用 / 不适用

- 适用：宠物或家居收纳方向、要写类目差异。
- 不适用：把本卡绿灯当成「宠物都能做」；服装/3C 差异未给数值。
- 站点/类目差异：默认 US；其他站点审批另核。

## 证据

宠物合规速查（SRC-0324，B）；一味君沙龙笔记家居收纳段（SRC-0085，C）。

## 反方 / 已知冲突

沙龙「打开类目就找」是 C 级找法，不替代 B 级十查与难度。官方趋势课里的细分增长数字不当本卡阈值。
