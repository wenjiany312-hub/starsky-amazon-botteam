## 结论（一句话，可直接被下游引用）

1688 搜货的三条实测规律：英文词基本无效（drone landing pad = 0 条）；词堆太长/过滤太严必落空（长尾+地域过滤 = 0 条）；品类词会混入整机/玩具等跨品类污染，要靠属性词组合（反光/折叠/可印图案/跨境）与人工剔除兜底。

## 机制 / 原因

1688 商家标题是中文属性词堆叠，英文词与学术长尾命不中标题；热品类词（无人机）会吸出整机卖家。有效信号藏在「品类词 × 属性词 × 跨境标记」的组合里，同一供应商会同时被多个组合命中——重复命中本身就是相关性证据。

## 操作 / 参数

1. 第一轮：品类中文名词（停机坪/起降垫/航模停机坪）。
2. 第二轮：属性词组合（折叠+反光+可印图案；防水+收纳袋+跨境亚马逊）。
3. 第三轮：相邻工艺词兜底（户外防水折叠垫/野餐垫/印刷垫）供 B 类池（KC-0054）。
4. 剔除规则：整机/玩具/跨品类污染直接剔除；同一供应商被 ≥2 个组合命中升级为重点。
5. 英文词与超长尾只做验证性搜索，预期 0 条，不据此判断「没货源」。

## 适用 / 不适用

- 适用：1688 MCP 或人工搜货的词表设计；判定「精准货源稀缺」前先过本卡。
- 不适用：标品词（品类词即精准）；据此断言某品「1688 无货」——0 条常是词问题不是货问题。

## 证据

15 轮搜索记录表：英文 0 条、长尾+过滤 0 条、属性组合 2-7 条（SRC-0453 §2）；竞品标题属性词反推法（SRC-0455 §2.1）。

## 反方 / 已知冲突

暂无。注意与「精准货源稀缺 → 转 B 类开发」的因果链：是搜词穷尽后才下此判断，不是第一轮 0 条就下。
