## 结论（一句话，可直接被下游引用）

蓝海打分公式（实跑经验值）：需求 0.30 + 竞争 0.30 + 利润 0.25 + 趋势 0.10 + 合规 0.05。饱和区设计是关键——月销 <100（没需求）或 >20000（大池红海）、评论 <30（验证不足）或 >10000（壁垒成型）直接记 0 分，不用肉眼再排。

## 机制 / 原因

权重把「有需求且没那么卷」放在 60%，利润 25%——对应精铺「先保证能活再谈爆」的逻辑。双侧饱和区（太冷/太热都归零）把中间带（月销 500-5000、评论 100-2000）定义成蓝海观测带，与 KC-0015 广告效率观测带、KC-0001 精铺月单分界同一思想：阈值就是模式选择。

## 操作 / 参数

1. 打分只对硬过滤幸存者执行（KC-0063 阶段 3 之后）。
2. 月销/评论取工具实测值；毛利用「(售价-采购估-FBA)/售价」，采购价取 1688 分位估算。
3. 趋势分按上架时间线性衰减：<6 月新品满分，老品 0 分——把「好做的已被做完」编码进公式。
4. 每类目取 TOP5 输出，不让单类目淹没总榜。
5. 分数只排序不立项：TOP 仍须过 KC-0065 人工复核与十查。

## 适用 / 不适用

- 适用：批量候选的相对排序；精铺初筛自动化。
- 不适用：绝对决策（分数高 ≠ 能做）；标品大牌类目（评论饱和区口径需重设）；把权重当官方值照抄。

## 证据

打分公式与五子项规则表（SRC-0501 §2.1-2.2）；TOP10 实跑评分输出（SRC-0501 §3.1/§4.1，蓝海分 17.9-25.2 区间）。

## 反方 / 已知冲突

权重无官方依据，纯单次实跑设定；评论饱和区（100-2000 满分）与难度评论区间法（KC-0020 系口径）角度不同——前者打分排序、后者难度判定，串联使用。
如何验证：对同一批候选改权重（如利润 0.35）重排，观察 TOP5 是否稳定；强推品上线后回看打分与实际的偏差。
