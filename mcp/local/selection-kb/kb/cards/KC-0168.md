## 结论（一句话，可直接被下游引用）

新品进入难度 = 头部集中度系数×0.4 + 评论壁垒系数×0.35 + 价格战系数×0.25；评论壁垒按 Top10 中位评论数分带（<500→0.5、500-2000→0.7、>2000→1.0），总分 0-0.3 容易、0.3-0.5 中等、0.5-0.7 困难、0.7+ 不建议进入（经验值，2026-09-17 提取）。

## 机制 / 原因

三个系数把「新品能不能挤进去」量化成单一可比数：头部集中度吃掉自然位、评论壁垒抬高信任门槛、价格战压缩利润空间，三者任一恶化都该反映在总分里。评论壁垒用「中位数」而不是头部最大值，是为了不被单条万评老品拉爆口径。与 KC-0014 评论区间难度（按评论量级占比）互补：本卡给出合成系数，可直接进报告评分，区间法仍是需求闸门本体。

## 操作 / 参数

1. 头部集中度系数 = Top3 销量占比（0-100 映射到 0-1）。
2. 评论壁垒系数 = min(1.0, Top10 中位评论数÷1000)，再按 <500/500-2000/>2000 三带校准为 0.5/0.7/1.0。
3. 价格战系数 = Top20 中低于建议定价的竞品占比。
4. 加权得难度分，报告必须展示计算过程 + 分档结论；0.7 以上直接「不建议进入」，不写「谨慎」。
5. 计算前先按 KC-0013 锁相似产品集合，异形态头部不进 Top 口径（KC-0017）。

## 适用 / 不适用

- 适用：市场调研报告的难度量化段、候选横向排序、给老板的进入难度一句话结论。
- 不适用：替代十查与灰手段判读（刷出来的低难度先打回）；品牌垄断类目单看系数会低估（配合 KC-0124）。
- 站点/类目差异：0.4/0.35/0.25 与 500/2000 分带为美国站经验值；重资品类建议上调评论壁垒权重。
