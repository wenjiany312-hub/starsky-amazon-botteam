## 结论（一句话，可直接被下游引用）

在运营品放量（加广告/冲排名）前先做差评集中度体检：1 星占比 ≥10% 且差评关键词指向**同一个可修缺陷**（案例：脚踏连杆脱落）时，修品是 P0——顺序固定为「修缺陷 → 修 Listing 截断 → 重建广告」；缺陷不修，广告加码等于给差评放大器供电（推论，2026-05-17）。

## 机制 / 原因

差评集中指向单一缺陷意味着：转化率的漏损是产品性的，不是流量性的；此时任何广告优化都只是把更多流量送进同一个漏点。同时差评会随销量放大（销量↑→差评绝对数↑→星级↓→转化率再↓），形成雪崩。反过来，这个体检也是选品信号：竞品差评集中缺陷 = 自己开品时的第一改良点（与 KC-0077 低评分机会池同源，视角从「挖机会」转为「设闸门」）。

## 操作 / 参数

1. 体检项：①1 星占比（阈值 10%）；②差评关键词聚类——指向同一物理缺陷、且该缺陷可通过换料/改结构/加配件解决；③Q&A 中重复出现的担忧（气味/安装/容量）。
2. 判定：①②同时命中 → 放量冻结，修品列 P0；仅①命中 → 先查评论真实性再定；差评分散无共同根因 → 不冻结，按常规优化。
3. 修品动作：缺陷项反馈供应商改模/换料，样品复测后更新五点与 A+（新卖点=已修复证据）。
4. 修品期间同步做文案与广告准备但不放量：修复 Listing 截断/五点首条损伤、按 SRC-1019 口径补广告真空词（SIF 大词 0 点击 → 精准组待命）。
5. 放行：缺陷修复确认（新批次或说明页生效）→ 按新卖点重写文案 → 广告才允许加码。

## 如何验证

- 案例：狗便桶 3 变体诊断（2026-05-17）——1 星 10%、"rod fell off" 差评聚类 + Q&A 气味担忧 → 判定 P0 修品，广告重构方案全部排在修品之后。
- 复测：修品后新批次差评中该缺陷关键词出现频次归零/大幅下降，1 星占比回落 <5% 为修品有效。

## 适用 / 不适用

- 适用：在运营品加投决策前的体检、老品重推前的诊断、竞品差评驱动的开品改良点选择。
- 不适用：纯供应链断货/涨价的放量推迟（那是库存闸门，不是质量闸门）；恶意差评攻击（走申诉，不改品）。
- 站点/类目差异：差评样本 <30 条时聚类不可靠，先积累评论再判。

## 证据

宠物垃圾桶 UK 全面诊断：差评聚类 → P0 修品顺序 + 广告真空词待命（SRC-1025 §5/§11、SRC-1019 §3）。
