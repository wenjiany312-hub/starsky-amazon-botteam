## 结论（一句话，可直接被下游引用）

AI 蓝海漏斗固定五段：种子词扩展候选池（642）→ 硬过滤 8 项约束（剩 68，砍 89.4%）→ 蓝海打分公式取每类目 TOP5（剩 10）→ 1688 端到端验证（6 个）→ 报告与人工裁决（强推 2 + 备选 4）。砍单大头在硬过滤——先按「无强制认证、<40cm 轻小件、$15-50、毛利≥40%」的卖家友好标准把不可做的物理剔除，再谈打分。

## 机制 / 原因

顺序即效率：硬过滤是零成本规则（认证/尺寸/价格带/毛利下限），放在打分前避免给注定不可做的品浪费 API 与打分算力；打分只解决「剩下里面谁更蓝海」；1688 验证只对 TOP 候选做（每条验证都是真实询价成本）。这与 KC-0030 深研漏斗（粗筛→深研→供应链 2-3）同构，是把该纪律工具化的实跑样本。

## 操作 / 参数

1. 阶段 2：16-36 个种子词（自有 SKU 反推 + 类目词）扩展候选池，数百 ASIN 量级。
2. 阶段 3：8 项硬约束一次性过滤（案例砍 89.4%），输出物为 asins_filtered.json。
3. 阶段 4：按打分模型（KC-0064）出每类目 TOP5。
4. 阶段 5：TOP 候选逐个过 1688 相似品验证，拿供应商链接与三档价格（散拿/50 件/500 件）。
5. 阶段 6：报告写明强推/备选/观望三档，人工拍板（KC-0065 复核点）。

## 适用 / 不适用

- 适用：美国站精铺/从0到1的批量初筛；有 MCP 数据源时的自动化漏斗。
- 不适用：替代人工深研与十查（漏斗只出候选）；硬过滤口径照抄（认证/尺寸/毛利标准应按自家资金与资质重设）。

## 证据

漏斗结构表与各阶段砍单比例（SRC-0501 §1.1-1.2）；卖家友好标准（SRC-0501 头注）。
