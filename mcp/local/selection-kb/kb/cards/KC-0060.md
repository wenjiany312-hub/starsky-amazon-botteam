## 结论（一句话，可直接被下游引用）

新品开发十步固定顺序：方向确认 → 竞品分析 → 市场调研（能不能做）→ 1688 供应链（能不能稳定做出来、多少钱）→ IP/外观/关键词侵权（哪些不能碰）→ **人工 go/pivot/abort 决策** → 关键词研究 → Listing → 主副图/A+/视频 → 广告架构。两条硬规则：市场判断非负面才去找货源；IP 边界明确后才许拓词。

## 机制 / 原因

顺序即成本：先市场后货源避免「有货才找市场」的沉没；先 IP 后关键词避免把品牌词、patented 暗示带进 Listing 和广告再返工。第 6 步强制人工停顿（go / pivot 换结构定位价格带 / abort），把 AI 流水线产出与资金决策分开——机器给依据，人拍板。

## 操作 / 参数

1. 1-3 步产出市场报告，核心问题只有「能不能做」。
2. 第 4 步供应链报告按 KC-0055 联动 SOP 执行。
3. 第 5 步输出 IP 黑名单（品牌/型号/外观/专利结构/颜色商标/图文字），供第 7 步拓词时过滤。
4. 第 6 步三值决策：go / go_with_modification / pivot / abort，写明理由后放行后续步骤。
5. 各步产出物归档命名（市场调研报告、供应链分析、IP 排查、关键词包），下一步只吃上一步的归档件。

## 适用 / 不适用

- 适用：有绝对竞品标杆的新品开发全流程；AI Agent 编排时的步骤护栏。
- 不适用：纯跟卖/铺货模式（无开发环节）；顺序不可为省时间压缩并行 IP 与关键词。
