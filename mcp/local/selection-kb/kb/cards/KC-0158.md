## 结论（一句话，可直接被下游引用）

1688 页面上的功能宣称（发光/夜光/防水/静音…）在**实物或供应商书面确认**之前，一律不得进入卖点假设、词库和文案——案例：儿童斗篷按「发光」方向做完词库与 Listing v2，拿实物才发现是蕾丝款无发光功能，方向作废重定义为女巫蕾丝 3 件套，glow 词作废、cape/kids/halloween/witch 词根保留，全部下游产物重排（实测，2026-09-05）。

## 机制 / 原因

1688 标题/详情的功能词是供应商的引流话术，不是产品事实；越早把它当事实，词库、文案、图片、竞品分组的沉没成本越大。实物到手（或样品视频+书面确认）是唯一能关闭这个不确定性的动作。实物否决不是失败——它发生在「下单前 + 旺季窗口内」就是成功，代价只是重排产物；拖到上架后才发现，就是季节来不及 + 差评。

## 操作 / 参数

1. 词库准入规则：功能宣称词（glow/night light/waterproof…）进入词库前必须挂「待实物验证」标记，验证通过才允许进精确组与标题。
2. 实物验证点：下单前向供应商索要实物/样品视频 + 尺寸表 + 材质成分书面确认；核心功能逐项打勾（案例：发光 → 实物无 → 否决）。
3. 否决后的重排清单：①卖点重定义（案例：荧光材质 → 蕾丝质感+3件套+2合1穿法）；②词根重排（功能细分词作废、形态词保留）；③Listing/主副图按新定义重写；④竞品池分级按新卖点重排（原发光竞品降级为参考观察）。
4. 时间纪律：季节品把「实物验证完成」设为下单前置闸门，与备货窗口一起倒排（案例 9/10 下单前必办、9/15 窗口截止）。
5. 文案事实锁：未验证项在文案里标 conditional/blocked，不出现（案例：无帽兜、无发光 = 禁止出现；尺寸数字 conditional）。

## 如何验证

- 案例：20260903 旺季选品 HANDOFF——决策 B 实物否决记录、词根重排口径、下单前必办清单（SRC-1129）；Listing v3 按新定义重写并附 23 张 1688 实拍图证（product_truth_locks）。
- 复查：抽 3 个在途新品，检查其词库中是否仍有「未验证功能词」在精确组里跑广告。

## 适用 / 不适用

- 适用：季节品/新供应商首单、功能宣称类卖点（发光/电动/防水/静音）、开品中期的方向重定义。
- 不适用：尺寸/颜色等下单必改项（走打样流程，不必上升到方向重定义）；纯外观差异。
- 站点/类目差异：季节品代价最大（窗口硬截止），标品可承受小幅重排。

## 证据

20260903 旺季选品交接卡：决策 B 重定义 + 词根重排 + 窗口倒排（SRC-1129 全文）；Listing v3 事实边界标注（无帽兜/无发光禁出现、尺寸 conditional、材质 blocked）。
