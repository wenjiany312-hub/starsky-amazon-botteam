## 结论（一句话，可直接被下游引用）

Cerebro/词族表逐词读两件事：自然排名普遍靠前（2-5 位）而广告排名大面积空缺（"-"）= 该市场自然流量为主、广告竞争温和，新品自然卡位即可；叠加搜索量趋势上涨（↑%）= 关键词级进入窗口（经验值，2025-07 课 41/25/65）。

## 机制 / 原因

广告位空缺说明没有玩家愿意为这个词出价——要么需求被自然结果满足，要么词太新没人盯。配合趋势箭头能区分「温和但没需求」与「温和且在涨」：后者才是窗口，前者只是冷清。

## 操作 / 参数

1. 对核心词跑词族分析，逐词记录：搜索量/趋势%/自然排名/广告排名。
2. 标出「自然位 2-5 + 广告位空缺」的词集（抹茶 matcha set kit/gift set 案例、bachelorette 杯广告排名全空案例）。
3. 只对趋势 ↑ 的子集判「进入窗口」；趋势 ↓ 的（如 -13%）即使空缺也不进。
4. 修饰词趋势（velvet/black/stackable/with drawers 全线 ↑）同时读作变体与差异化方向。
5. 词级窗口只是信号，立项仍过难度双法与利润线。

## 适用 / 不适用

- 适用：词族级机会识别、新品进场时机判断、变体方向挖掘。
- 不适用：替代 listing 级四失衡扫描（KC-0006）——两层级并用，词级更早、 listing 级更实。
- 站点/类目差异：广告空缺在品牌垄断类目可能意味着「投了也没用」，先看自然位是否被单一品牌锁死。
