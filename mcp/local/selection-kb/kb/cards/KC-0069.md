## 结论（一句话，可直接被下游引用）

选品方向用三渠道同时打分：Amazon（成交侧）、TikTok（社媒种草侧）、Google Trends（搜索趋势侧）。矩阵判读：三路全热=强信号立刻验证供应链；Amazon 热+TikTok 冷=需种草才能起量；TikTok 热+Amazon 冷=早期信号抢先布局；只有 Trends 热=萌芽期提前卡位；三路全冷=暂缓。各渠道有独立阈值（TikTok >1000 条视频、Amazon 月销 10K+、Trends Breakout +5000%）。

## 机制 / 原因

三个渠道处在消费链路的不同位置：Trends（意识）→ TikTok（种草）→ Amazon（成交）。单渠道信号都有假阳性（Trends 涨但没人愿意在亚马逊买；Amazon 热但已被头部锁死），交叉定位能回答「这个需求走到链路哪一步了」，从而决定是提前布局还是立刻跟进。与 KC-0061 VOC 前导/滞后逻辑同源，是把同一思想落到三个免费渠道的轻量版。

## 操作 / 参数

1. Amazon：爬搜索结果与畅销榜，看 boughtPastMonth、评论数、评分分布、广告密度（sponsored 多=竞争激烈）。
2. TikTok：搜索页数视频量与点赞、Creative Center hashtag 播放量（官方 API 不开放，手动/浏览器替代）。
3. Google Trends：12 个月趋势线、季节峰值、Related queries 上升词、Breakout 词。
4. 套矩阵出五档结论（强信号推进/保留观察/暂缓），结论只到「是否进入供应链验证」。
5. 输出固定模板报告（调研日期+三渠道数据+交叉结论+下一步：专利检索/合规确认/≥3 家询价/利润测算）。

## 适用 / 不适用

- 适用：单品方向的快速体检（半天级）；给漏斗候选做前置信号过滤。
- 不适用：替代 SIF/卖家精灵的深度数据（矩阵是方向判断不是立项终裁）；TikTok 阈值跨品类照抄（品类内容生态差异大）。
