## 结论（一句话，可直接被下游引用）

大盘入口在**目标类目月销榜**从上往下找异常值，不从全站 BSR 头部硬挤；时间×销量只解释已经找到的异常，不当漏斗第一刀。快扫出候选，不做立项终裁。

## 机制 / 原因

KC-0006 列出四个探测器。本卡补「在哪张表上扫」：床垫/枕头级老品占着大盘头部，新品没机会（课 37 经验口径）。近月上架、季节尾声、站外短火都会让「上架短却爆量」失真，所以时间探测器不能当第一筛。

## 操作 / 参数

1. 锁一个类目节点（不是全站），用市场 MCP 或用户月销榜导出，按月销从上往下扫。
2. 用四探测器标异常（见 KC-0006）；「近几月上架」只做备注，不作主筛。
3. 每个候选最少 8 列：候选 / 核心词 / 月销 / 评论 / 上架天数 / 自然词与广告词 / 命中探测器 / 风险（刷、季节尾声、品牌词、侵权）。
4. 输出 5–10 个后停，交难度双法；本步不得写「可以做」。

## 适用 / 不适用

- 适用：从零扫、蓝海、精铺灵感层。
- 不适用：用户只要完整立项报告、只要单点算难度、只要节日表。
- 站点/类目差异：默认 US 类目月销榜；缺数标待填，不编销量。

## 证据

trend-signal-scanner（SRC-0310）；pilot 从零找品先扫（SRC-0306）。蓝海单品报告（SRC-0242/0253）里的月销与供需比不当本卡阈值。
