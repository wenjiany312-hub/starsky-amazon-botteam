## 结论（一句话，可直接被下游引用）

把 BSR Top100 样本按「价格带×产品形态」交叉成矩阵，每格看四个数：样本数、月销量、单 ASIN 销量效率（月销÷样本数）、增长代理（格内月销量增长率中位数，截尾 -100%~+500%）。机会格=单 ASIN 效率高 + 增长代理正 + 样本少的低龄训练型结构（案例：仅 3 样本却 1075 月销、单 ASIN 358、增长 +21%）；主流形态的图案升级不是机会，结构升级才是（D 级实跑口径，2026-07-29）。

## 机制 / 原因

只看价格段总量或只看形态总量都会错位：主流甜点带销量大但同质化集中，真机会常在「大带里的结构空档」或「小带里的高效率格」。单 ASIN 效率把「供给少」和「没人要」区分开——样本少但单 ASIN 卖得好=供给空白；样本少且单 ASIN 也差=需求空白。增长代理用中位数+截尾是为了防单链接爆量污染方向判断，同时必须声明它不是真同比。

## 操作 / 参数

1. 取 BSR Top100 明细（含价格、月销量、月销量增长率、上架日期、标题卖点）。
2. 价格带按样本分布固定 5 档（不机械等分）；形态按标题/参数/卖点规则聚成 3-6 类；CMF（色彩图案）单独聚类。
3. 逐格计算：样本数、月销量、销售额、单 ASIN 效率、增长代理中位数（截尾）、新品数（≤365 天）。
4. 机会格判读：单 ASIN 效率高于主流格 + 增长代理为正 + 样本少 → P0 结构机会；效率高但增长为负 → 只有结构升级才值得做第二锚点；图案拥挤格 → 从满版图案转向可替换面板/低饱和/结构辨识度。
5. 结论口径：必须写「增长代理不可当真实同比」；验证方法=连续 3 个月历史序列复核后才能升级为趋势结论。
6. 外部合规随行：儿童类目标注 CPC/CPSC 认证要求，作立项检查清单（KC-0095）。

## 适用 / 不适用

- 适用：BSR Top100 类目的切入点快扫、新类目第一轮结构机会盘点、垂直类目找结构升级方向。
- 不适用：替代完整市场调研（矩阵是机会筛选不是立项调研）；非标服饰类形态分类口径需重定。
- 站点/类目差异：形态分类规则依赖标题质量，DE/JP 站需重写规则。

## 证据
