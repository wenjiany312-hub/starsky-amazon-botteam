# 星空产品推广知识库 MCP

注册名 `promotion_knowledge_base`。只输出推广打法建议和出处，不登录后台，不改价不改库存。

公开版请运行安装包的「安装产品推广知识库」或「安装与更新」。
安装位置固定为用户目录 `.codex/mcp/starsky-promotion-kb`。
S4拟策略/重推/排名恢复先调 `kb_scenario_rules(产品类型, 生命周期, 推广场景)`，掉量掉位先抽短症状再 `kb_diagnose`，手册用 `kb_playbook`。
阈值是候选口径，用户利润账与合规黑名单优先；它不读本店广告账户，也没有改价工具。
S1选品仅作推广可行性参考，不单独立项；S5巡检只给原因树和出处。
