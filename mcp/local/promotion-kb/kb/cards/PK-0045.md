## 结论（一句话）

把"什么时候关词、什么时候否词、什么时候放大"变成**自动化规则**而不是人工拍脑袋：**点击-无单按周期递增宽限（7/14 天 12 击 → 30 天 10 击 → 60/90 天 8 击）自动暂停；有单但 CVR<8% 人工复核暂停；ROAS<3 的商品定位暂停；CVR≥20% 且点击≥15 的好词拉出放大**——规则跑机器，人只看 8-12 击的灰色区与放大决策。

## 自动规则表（可直接配置到 ERP/领星类工具）

| 对象 | 触发条件 | 动作 |
|---|---|---|
| 关键词广告 | 7/14 天 12 击 0 单 | 自动暂停 |
| 关键词广告 | 30 天 10 击 0 单 | 自动暂停 |
| 关键词广告 | 60/90 天 8 击 0 单 | 自动暂停 |
| 关键词广告 | 8-12 击 0 单（灰色区） | **人工**：核心词→降 bid+优化页面/促销；非核心→直接关 |
| 手动 ASIN（商品定位） | 7/14/30/60/90 天任一周期 8 击 0 单 | 自动暂停 |
| 自动广告 | 7/14/30/60/90 天任一周期 12 击 0 单 | 加入否定投放 |
| 关键词/ASIN | 有出单但 CVR<8%（任一周期） | 人工确认暂停 |
| 商品定位 | 有出单但 ROAS<3（任一周期内） | 自动暂停 |
| **放大：好词** | CVR≥20% 且点击≥15 | 拉出单独投放；组内其他词关停，预算留给最好 1-2 词 |
| 放大：拓 ASIN | 转化好、ROAS 高的词 | 用该词拓 ASIN 定向 |

## RPA 新增活动频率（供量用）

| 品类 | 频率 |
|---|---|
| 季节性产品 | 起势期**每半月**至少新增一次活动 |
| 节日性产品 | 起势期**每周**至少新增一次 |
| 普品 | **每月**至少新增一次 |
| 红线 | **ROAS<1 的活动直接关闭，优化后重开** |

## 适用 / 不适用

- 适用：成熟链接的日常运维自动化（活动多、人工盯不过来）；给新同事的"关词/否词标准"。
- 不适用：断货期/放量冲刺期（此时曝光波动大，规则会误杀——如 D0 后首周应暂停自动规则，见 PK-0005/SC-断货重推）。

## 证据

- SRC-0018（广告自动化，领星自动规则配置，B 级）：点击阶梯/ROAS/CVR/放大线/新增频率全套。

## 反方 / 已知冲突

- 点击阈值与我们的"≥20 击 0 单否定"（PK-0029 纪律）相比更激进（8-12 击即入灰色区）——差异来自客单价与 CPC 量级：高客单 CPC 高时用本卡更严的阶梯；低客单标品（CPC ~$1.5）建议用 12-20 击档，实施前按自己盈亏线换算；
- 自动化会误杀长尾词的"养词"价值（低点击高潜力词）——灰色区必须人工，不可全自动。
