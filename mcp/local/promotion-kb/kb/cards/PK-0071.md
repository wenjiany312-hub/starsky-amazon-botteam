## 结论（一句话）

清货第一步不是降价而是**归因**：①选品误判型（首批卖光后大量备货遇满屏低价竞品）；②季节型（高峰低谷差大、供应链/资金/技术撑不住大类目季节品）；③口碑塌方型（差评/投诉/反复下架申诉）；④管理型（补货与推广脱节）。归因决定路径——季节型等下一个旺季窗口、口碑型先止损、管理型改流程；然后按"降价 → Coupon/秒杀 → 站外放量 → 批发/清货商 → 弃置销毁"的阶梯分阶段执行并追踪数据，避免一步跳到最低价。

## 分阶段阶梯（按库存天数与时点排）

| 阶段 | 动作 | 目标 |
|---|---|---|
| 预警 | 库存天数>90 纳入监控，先提价观察动销 | 确认真滞销 |
| 一阶 | 降价 5-15% + 常开 Coupon | 用利润换动销 |
| 二阶 | 报 LD/秒杀 + 站外 Deal 放量（控制亏损预算线） | 快速去化 |
| 三阶 | 批发打包/Woot 等清货渠道/清货商收购 | 回笼现金 |
| 末阶 | 移仓换标翻新重推（PK-0064）或弃置销毁 | 止损 |

## 适用 / 不适用

- 适用：淡季维持与衰退清仓决策；旺季前滞销预警。
- 不适用：新品期正常爬坡（误判为滞销会错杀）。
