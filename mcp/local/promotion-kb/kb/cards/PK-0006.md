## 结论（一句话）

重推达标五条线（经验值，2026-03 口径）：**评论 ≥100 条、评分 ≥4.3 星、核心词自然位进首页、广告 ACOS ≤30%、备货 = 销售额 3 倍**——验收时逐条打勾，缺哪条补哪条。

## 阈值表

| 指标 | 绿灯线 | 说明 |
|---|---|---|
| 评论数量 | ≥100 条 | 基本竞争力门槛 |
| 评分 | ≥4.3 星 | CVR 保障线（决策树立项线为 4.0，冲刺线 4.3） |
| 核心词排名 | 首页 | 自然流量主入口 |
| 广告 ACOS | ≤30% | 关键词上首页经验线 |
| 备货 | 销售额 3 倍 | 防二次断货 |

## 适用 / 不适用

- 适用：重推验收、反超战复盘。
- 不适用：品牌高客单品（评论门槛应按类目 Top10 实际值重设，勿照搬 100 条）。
