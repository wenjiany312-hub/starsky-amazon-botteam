## 结论（一句话）

H10 反查后的词库加工标准流：**四维筛选**（自然排名=转化力、广告排名=广告价值、IQS≥700+Xray 人工验证=精准度、流量竞争+合规=价值与安全）→ **三维归类**（精准度分档、长度分层、词根归类）→ **投放闭环**。分档核心标尺：搜索结果前 10 同类占比 **≥90% 绝对精准 / 50-90% 相对精准 / 20-50% 一般精准 / <20% 废弃**。

## 执行参数

| 环节 | 参数 |
|---|---|
| 反查竞品 | 3-5 个头部 ASIN：BSR 前10+同类目+相似价格+相似功能+当前变体 |
| 精准度验证 | IQS ≥700 初筛 + Xray 看前 10 同类占比定档 |
| 词根建组 | Frankenstein 提词根 → 精准组(高bid)/词组组(中bid,周期否词)/广泛组(低bid,严格否词) |
| 新品期 | D0-7 只投绝对精准大中词（高bid精准）；D8-14 加相对精准长尾（词组） |
| 否词线 | CTR <0.3% 或 CVR <1% → 否定（每日检查广告报告） |
| 合规 | 删侵权词/禁售词/无关词 |

## 适用 / 不适用

- 适用：keyword_package.yaml 建库标准流（工具导出数据统一按此加工）。
- 不适用：无 H10/IQS 口径时（用卖家精灵相关性+人工前10检查替代，见 PK-0021）。
