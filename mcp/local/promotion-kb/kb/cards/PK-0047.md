## 结论（一句话）

大促复盘按**六维框架**跑：全局（销量/转化/流量/广告依赖度）→ 工具（SP/SB/SBV 各自的量-率-成本）→ 广告位（首页/商品页/其余）→ 搜索词（大词/品牌词/品类词）→ DSP/上层（拉新 vs 收割）→ 依赖度趋势；**大促的胜负手是"爆发力流量"与"广告依赖度"两条线**——流量跌幅决定销量跌幅，点击量的持续增长才是订单增长的地基。

## 六维框架与实证结论（黑五网一案例）

| 维度 | 看什么 | 案例结论（可复用的判读） |
|---|---|---|
| 全局 | 销量/销售额/Sessions/CVR/广告依赖度 | 销量跌因 session 大跌（缺爆发力流量）；**CVR 上涨绝对值 > 流量下跌绝对值 → 销量跌幅收窄**；链接越成熟广告依赖度越低（自然单兜底 ROI） |
| 工具 | SP/SB/SBV 的量-率-成本 | SP 贡献最大点击与转化但 CPC 贵（优质位供不应求）→ **持续占领**；SB 大促期转化率接近 SP（非大促差很多）→ **大促出价拉满**；SBV 成本最低 ROI 高 → **破圈工具**（本类目天花板低就去相关类目抢点击） |
| 广告位 | 首页 / 商品页 / 其余 | **首页** ROI 最高且 CPC 下降 → 提高花费占比；**商品页** ROI 最低（防御成本走高）→ 非主力 ASIN 降防御力度；其余位可设加价增幅 → 提高占比 |
| 搜索词 | 大词/品牌词/品类词 | 单个大词曝光接近边际 → **"一超多强"多点开花**（1 个一级大词+多个二级大词）；品牌词花费降但销售稳=品牌收割健康，外溢不多；**品类词目的=低 CPC 高 ROI，偏离即重构（多词低 CPC 高 ROI）** |
| DSP/上层 | 拉新 vs 收割比例 | 只收割不拉新 → 上层人群萎缩、CPM 反涨（供过于求）→ **切 30% 预算做拉新**，形成正循环；品牌声量拉新预算占比 ≤5% |
| 依赖度 | 广告依赖度趋势 | 监控依赖度走低是健康信号（自然单兜底）；素材需按节日属性持续 AB test（圣诞/情人节属性） |

## 年度品线财务模型（SRC-0005 数据字典）

按月滚动六块口径（复盘与备货决策共用）：
1. **采购**：期初/采购入/本期支付/期末/**负债率**；
2. **物流**：期初/发货/支付/期末/负债率；
3. **库存**：采购入库存/国际在途/可售库存/库存合计/库存单价/库存总额/**销售比例**；
4. **销售**：销售量/客单价/销售额/**回款率**/回款额（美元/人民币）；
5. **净现金流**：综合成本/头程比例/**采购成本占比**；
6. **净利润**：净利润率。

用法：**月度复盘对照"计划 vs 实际 vs 完成率"三行**（本案完成率行按 1/0.8 等比例呈现）——与 PK-0008 的"备货=销售额 3 倍"、库存天数预警配套使用。

## 适用 / 不适用

- 适用：大促（黑五/网一/PD）后 1-2 周的复盘与下轮策略；年度/半年经营复盘的指标清单。
- 不适用：单链接小改动的日常复盘（用 PK-0022 的 7/14 天口径就够）；本案为大卖账户（月销万单级），绝对值不可照抄，取维度与判读逻辑。

## 反方 / 已知冲突

- 案例含 DSP/AMC 层（需要 DSP 投放与亚马逊营销云权限）——我们当前只跑 SP（少量 SBV 待建），DSP 维度先作知识储备，不列执行项；
- "切 30% 预算拉新"是大卖口径，与我们"以量取胜 30 天窗口"（PK-0005）的预算结构不同，小账户先保效果位。
