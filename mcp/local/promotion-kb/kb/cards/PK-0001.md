## 结论（一句话）

老品流量下滑先按固定顺序做五层诊断——**曝光（自然/广告谁掉）→ 点击率（主图/价格/跟卖）→ 转化率（差评/价格战/Listing老化/退货）→ 关键词（收录/出单词排名/被卡位）→ 运营因素（断货/广告占比失衡/促销中断）**，先定位再动手，禁止无诊断直接加预算。

## 诊断树（症状→原因）

| 层 | 症状 | 指向原因 |
|---|---|---|
| 曝光 | 自然曝光骤降 | 关键词自然排名暴跌 |
| 曝光 | 广告曝光下降 | 广告排名下降 / 词被否定 |
| 曝光 | 两者同降 | 算法变化 / 市场大盘下滑 |
| 点击 | CTR 走低 | 主图吸引力降 / 价格无竞争力（竞品挂Coupon）/ 跟卖 / 排名位置变化 |
| 转化 | CVR 走低 | 首页差评堆积 / 竞品价格战（ASIN定向抢流）/ Listing 老化 / 退货率上升 |
| 关键词 | 流量结构变差 | 收录减少 / 核心出单词排名下降 / 搜索习惯变化 / 被竞品卡位 |
| 运营 | 综合下滑 | **断货致权重丢失** / 广告单占比过大 / 促销中断 / 库存冗余 |

## 操作 / 参数

- 顺序执行：先看业务报告定曝光层，再逐层往下；每层给出明确"是/否"结论后才进下一层。
- 外部因素对照：平台大盘、竞品数量、价格战、季节性、算法变化（先排除外因再归因内部）。

## 适用 / 不适用

- 适用：成熟期下滑链接、断货重启前诊断、被竞品反超后的差距定位。
- 不适用：全新上架链接（无历史数据可诊断，直接走新品打法）。
