## 结论（一句话）

广告没有"通用最佳打法"——先按**决策顺序（目标 → 承接能力 → 流量结构 → 资源约束）**定基调，再选阶段策略：**新品期探索优先**（自动+词组+少量广泛，宽泛探索收集搜索词）、**发展期放量优先**（聚焦验证过的转化词抢位，预算必须匹配库存）、**成熟期利润优先**（只留高转化高利润词，用广告养自然、广告占比逐步下降）。

## 三阶段对照表

| 维度 | 新品期（探索） | 发展期（放量） | 成熟期（利润） |
|---|---|---|---|
| 核心目标 | 让系统理解产品、收集搜索词、验证承接 | 高转化流量集中到可控结构、推核心词自然位 | 降无效花费、提自然单占比、维护排名 |
| 广告结构 | 自动 + 词组 + 少量广泛 + 少量商品投放 | 精准 + 词组 + 商品投放 + 控预算广泛 | 精准 + 商品投放 + 品牌防守词 + 利润词 |
| 竞价 | 宽泛探索，不急于精准竞价；可略高于建议值 | 高转化词加价抢位 | 核心词精准锁定，防御竞品抢词 |
| 优化节奏 | 每周看搜索词报告：好词移入精准/词组，差词否定 | 收紧结构、低转化降/停、盯自然位推进 | 持续否词调价、控 CPC、向利润词倾斜、看 ROAS/TACOS |
| 红线 | 不要过度否词使流量过窄；先确保标题/主图/价格/评价能承接 | **预算匹配库存，避免"有流量、无库存"** | 目标是"用广告养自然"，广告订单占比应逐步下降 |

## 季节性产品的四节奏（节奏比预算重要）

| 阶段 | 时间 | 动作 |
|---|---|---|
| 预热期 | 旺季前 4-6 周 | 低预算自动 + 词组广告，收集当季搜索词，保持 Listing 活跃 |
| 爆发期 | 需求集中释放 | 精准词提价抢首页；商品投放拦截竞品；放宽预算 |
| 尾声期 | 需求回落 | 逐步降竞价、收窄关键词范围、为清库存做准备 |
| 淡季 | 低需求窗口 | 维持最低预算或暂停；可用站外内容维持热度 |

## 适用 / 不适用

- 适用：给任何链接"定当前阶段 + 选对应打法"的判层工具；各产品线当前所处阶段的校准。
- 不适用：把阶段当教条（同一链接的不同词可以处于不同阶段——分层管理，见 PK-0029 归类反推）。
