## 结论（一句话）

竞品调研要下钻到**子体级**：用"子体流量词数 ÷ 父体流量词数 = 变体流量词占比"与"变体评论占比"两个占比，找出家族的**主推子体**（流量与评论的承载体）——对标时打的是那个子体，而不是随便一个变体；占比为 0 的子体是"僵尸变体"（挂家族吃流量但无作为）。

## 字段体系（可直接复用的表头）

| 分组 | 字段 |
|---|---|
| 标识 | 变体 ASIN / 变体名称（Color/Size 属性）/ 父 ASIN / 图片 ID |
| 流量 | 子体流量词数 / 父体流量词数 / **变体流量词占比** |
| 评论 | 子体评论数 / 父体评论数 / **变体评论占比** |
| 排名 | 大类 / 大类排名 / 小类 / 小类排名 |
| 判定 | **是否占比最高子体**（1/0） |

## 判读规则（案例印证）

- **主推子体** = 流量词占比最高者（案例：Starter Kit 251/666 = 37.7%）→ 竞品对标、价格监视、ASIN 定向都对准它；
- **僵尸子体** = 流量词 0（案例存在多个）→ 说明对手只在主推子体上经营，其余只是规格占位；反推：如果我们有这类子体，要么激活要么收敛（对应 variant 矩阵纪律）；
- 评论占比 < 流量占比 = 该子体有流量没沉淀（评分/评论弱），是可攻击的缺口；评论占比 > 流量占比 = 老评价子体，防御力强；
- 与 PK-0013（家族互防）合看：自家变体矩阵做同样一张表，就知道"哪个子体在替家族扛流量"。

## 适用 / 不适用

- 适用：竞品家族拆解（选打哪个子体）；自家变体矩阵体检（谁是承载体/谁是拖油瓶）；ASIN 定向目标选择。
- 不适用：单品链接（无变体时字段退化，直接用 PK-0043 的单 ASIN 反查表）。

## 证据

- SRC-0027（竞品调研表精华版，变体级字段体系 + smoking kit 案例，B 级）。

## 反方 / 已知冲突

- 变体流量词数来自工具反查口径（覆盖率有限），占比用于**横向比较**可靠，绝对值勿当全量；
- "是否占比最高子体"标记有时多子体并列（案例中多个 1）——按占比数值排序判，不看标记位。
