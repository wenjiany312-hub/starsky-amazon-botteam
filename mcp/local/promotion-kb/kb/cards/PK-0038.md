## 结论（一句话）

A+ 内容是**品牌详情页的增产工具**（视频/增强图/自定义文案位/可购物对比图），官方门槛是**专业卖家账户 + 品牌注册**（自有 ASIN 才能投放）；官方效果数据：**基本 A+ 最高 +8% 销售，实施良好的高级 A+ 最高 +20%**——双线产品均已具备资格（品牌注册 + 已有 A+ 资产），本周期升级高级 A+ 是确定性收益动作。

## 官方要点（资格与规则）

- **资格**：需 Professional 销售账户（$39.99/月）+ 品牌注册（权利人或被授予 Brand Representative/Reseller 角色）；投放对象**仅限自有品牌 ASIN**。
- **内容形态**：视频、增强图片、自定义文本位、可购物对比图（comparison chart）等模块组合；内容类型（content type）在创建时选择。
- **AI 辅助**：标注 "AI Ready" 的模块可一键生成内容——选定文本/图片字段 → Generate content → 输入自有 ASIN 获取类目洞察。
- **审核**：提交后审核通过自动上线到所选语言站点；状态在 A+ Content Manager 查看。
- **成本**：A+ 内容本身免费（门槛是专业账户月费与品牌注册）。

## 发布五步流程（官方原文顺序）

1. 登录 Seller Central（确认专业账户）；
2. 品牌注册报名（或被授权角色）；
3. **Advertising → A+ Content Manager → Start creating A+ Content** → 选内容类型 → Add module（可叠加 AI Ready 模块）；
4. **Apply ASINs** → Apply Content（仅自有 ASIN）；
5. **Review & submit** → 审核通过自动上线。

## 效果与指标

| 层级 | 官方效果（Amazon internal data） | 运用 |
|---|---|---|
| 基本 A+ | 最高 **+8%** 销售 | 底线配置，所有主推 ASIN 必配 |
| 高级 A+（Premium） | 实施良好最高 **+20%** 销售 | 主推款升级目标；需更高内容质量 |
| 商品描述实验（MYE） | 优化后改动最高 **+25%** 销售 | 与 A+ 联动做 A/B（见 04 库 KC-0047） |

## 适用 / 不适用

- 适用：全部在售 ASIN 的 A+ 配置体检与高级 A+ 升级；新品上架即配基本 A+。
- 不适用：非品牌 ASIN（无资格）；把 A+ 当搜索排名工具（A+ 作用于转化与信任，不是关键词排名位）。

## 反方 / 已知冲突

- +8%/+20% 为亚马逊官方内部统计口径，非承诺值；实施质量差异大（"well-implemented"）——低质 A+ 可能无效甚至拖累，故本库规范卡要求模块顺序按转化逻辑排。
- 模块级尺寸规范（像素/字数上限）在后台 A+ 创建界面为准（公开页未逐项列出）；执行时以 A+ Content Manager 内的实时提示为最终依据。
