## 结论（一句话）

**广告没有独立权重**——老计划关掉、同设置重建，表现几乎一致（只冷启动几天）；人群数据积累在 **ASIN** 上而不是广告计划里，所以计划可以随时开关；广告表现由**访问行为 + 访问人群 + 出价**三要素决定——理解这点后，"广告权重"这个口头禅可以退休了。

## 核心论断与验证法

1. **"权重"的本义**：搜索算法史里的"加权的重要性"（关键词密度 → 外链投票加权 → 用户行为加权）；运营口中的"权重"多数是归因不明的口头禅。
2. **广告无计划级权重（可自证实验）**：把老计划停用，一模一样重建新计划——新计划冷启动几天后表现与老计划几乎相同。推论：**不必因"怕掉权重"而不敢重建活动**（与 PK-0045 的自动化暂停/重开纪律相互印证）。
3. **数据在主推 ASIN 上**：人群（潜客/新客）积累于 ASIN，不在 campaign——所以 PK-0015 的"广告压制自然"其实压的是**人群路径重叠**，不是"计划权重"。
4. **压制/重叠判定（两步法）**：
   - ① 后台免费流量占比 = 业务报告会话数 − 广告点击量（案例：60%）；
   - ② SIF 反查父体广告占比（案例：58.96%）；
   - ③ 差额（案例 18.96%）≈ 广告位与自然位**前后出现导致的重叠点击**——差额越大，压制越明显，动作=收缩让位（PK-0016 三诊断法同源）。

## 实务含义（怎么用）

- 优化对象从"保权重"改为三类可控项：**改行为**（Listing/价格/评价）、**调人群**（匹配方式/定向/否词）、**动出价**（bid/位置加成/分时）；
- 活动结构调整（拆分/重建/暂停）不必有心理负担——但**ASIN 层面的人群体感会保留**，所以重建后数据不会"从零"；
- 与 PK-0034（COSMO）衔接：人群与语义信号都在 ASIN 上累积，这正是"改链接先改 listing 认知"的底层原因。

## 适用 / 不适用

- 适用：广告归因诊断（尤其"ACOS 波动是不是权重掉了"类疑问）；活动重建/迁移决策；压制诊断。
- 不适用：把"无计划权重"误读为"权重不存在"——**ASIN 层的表现加权真实存在**（PK-0009 五因素）；也不适用于 SB/SD 的品牌级归因（本卡口径为 SP）。

## 反方 / 已知冲突

- "关掉重建表现一致"是作者自测结论（B 级经验），Amazon 未官方背书；实践建议在**低风险活动**上先验（长尾活动），主力活动仍按"能修不重建"纪律走；
- 重叠率 18.96% 为单案例数字，正常区间未标定——先做自己的基线（各产品线分别测一次），再按趋势对比。
