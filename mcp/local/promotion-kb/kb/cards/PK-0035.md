## 结论（一句话）

互补品词的**搜索者要的是别人的产品**，搜索结果页上我们的转化天生差（CPA $20-90 全亏）；但搜这些词落地到互补大卖详情页的访客才是完美受众——**正确姿势是关键词投放关死+商品定向打互补大卖详情页，同时把互补词的自然位当免费流量养**。

| Ads API 30 天 | 互补词系 CPA $20-90 全亏 | 关键词投放证伪 |

| 西柚点击份额 | 互补品头部品牌A 30% / 品牌B 12-24% | **定向标的=self-evident**：打这两家的详情页 |

| Ads API 30 天 | 某治疗语义词 3 击 0 单 | 治疗语义 negative 决策再次验证 |

## 可泛化规则（D 级推论，验证中）

1. 互补品词判据：搜索意图指向**另一品类商品**（洗耳液/湿巾/药）而非本品形态（清洁工具）→ 不做关键词投放。
2. ASIN 定向标的挑选：互补词 Top 点击份额前 2-3 名（详情页有流量），优先评分/价格弱于我们的。
3. 互补词自然位靠 Listing 语义覆盖（PK-0025/PK-0018）与出单权重自然生长，不专门投广告推。

## 适用 / 不适用

- 适用：宠物清洁类目所有互补词（洗耳液/湿巾/耳粉/修剪器）；其他类目"耗材 vs 工具/药"分家场景。
- 不适用：同品替代词（竞品词属 PK-0027 攻坚范畴）；互补品就是自家家族产品时（改为家族导流）。

## 反方 / 已知冲突

- SIF 口径下 dog ear cleaner 点击转化率 35.3% 很健康——但转化发生在大卖详情页，不代表我们能分到；勿误读为"值得投关键词"。
- ASIN 定向的转化也可能被大卖的 Coupon/低价截走（PK-0013 反制逻辑同样适用于我们打别人时）。
