## 结论（一句话）

词库不是"一张表"，而是**四段工具链**：采集（下拉框 a-z 拓词 / 工具反查表）→ 分析（三档精准分析表的数据字典 + 特征词频分析）→ 监控（坑位记录表 + 跟踪表模板）→ 复核（目标排名查询 + 标题规则批量查询）；每段都有现成模板/工具，串起来就是"词海打法"的日常运转底盘。

## 四段工具链

### ① 采集
- **前台下拉框拓词**（SRC-0032）：工具支持"基础采集/ a-z 采集"两种模式；a-z 模式在词根后自动拼 a..z 扩大覆盖（一个词可拓 226 个），词根清单放 `parm.txt` 一行一词；Win10 运行。
- **后台品牌分析**（SRC-0043）：品牌分析 → 亚马逊关键词搜索 → 输入词根，看该词根下各词流量。
- **ASIN/多 ASIN 反查表**（SRC-0030 / SRC-0037）：单 ASIN 表（日期×Buybox/Coupon/BSR/评分/自然·广告·推荐流量百分比）与多 ASIN 对比表（每词的流量份额 / 7 天展示量占比 / 自然排名(P页-页内) / SP 广告排名 / 展示位置类型）——多 ASIN 对比表是"竞品词位横评"的标准件。

### ② 分析
- **三档精准分析表数据字典**（SRC-0031/0041/0042）：每词一行，列 = 周搜索量｜周点击量｜周销售量｜点击转化率｜**CPR**（工具口径：冲目标排名所需单量，实施前核对工具说明）｜**SP/SB × 精准/词组/广泛 的最低价-平均价-最高价**（12 列竞价全景）｜Top3 产品（验证词的相关性与竞争格局）。
  - 用法：先在"一般精准"筛大盘词 → "相对精准"看属性词 → "绝对精准"定攻坚词；三档的竞价列直接作为出价区间底稿（与 PK-0030 梯度、西柚建议竞价交叉验证）。
- **特征词分析**（SRC-0039）：抓取竞品标题 + 评论数，按评论数加权提取高频**特征词**（材质/款式/人群/场景）——用于标题词根组合与属性词库；比人工读标题快一个量级。

### ③ 监控
- **坑位记录表**（SRC-0035）：按天记录每个词 `P页码 R页内位`（如 P1 R3），掉出前三页记 X——升降位趋势一目了然，是"推词是否有效"的第一手证据。
- **关键词跟踪表模板**（SRC-0036）：多 ASIN 分表 + Dashboard 总览，逐词每日排名，适合多链接并行监控（多条产品线可用同一模板分表）。

### ④ 复核
- **目标排名查询**（SRC-0040）：批量查 ASIN 的**上架时间 / 到 10000 名时间 / 完成目标时间 / 目标评论数**——用来定"新品起量基准线"。
- **标题规则批量查询**（SRC-0038）：批量校验标题是否违反平台规则（跑批量上新前过一遍）。

## 竞品选择与修饰词分类（SRC-0043 补充）

- **竞品选择**：① 第 1 大页选同类靠前 10 个自然位；② 榜单同类靠前 10 个；③ 新品榜前 5 名中同类产品；选择前先核对"核心词下小类目一致性"（≥95% 同类才可用，否则需看多个小类榜单）。
- **修饰词分类**：以 apron 为例——同品类修饰词按共性归类（场景/受众人群/属性），与 PK-0021 属性法、PK-0030 属性词梯度同一体系。

## 适用 / 不适用

- 适用：词库从 0 到 1 的搭建；日常词监控与出价底稿准备；多 ASIN/多竞品的横评表制作。
- 不适用：只有 ABA 无工具订阅的极简场景（用 PK-0021 的 ABA 分层 + 西柚免费额度替代）。

## 反方 / 已知冲突

- 工具表是"快照"——CPR/竞价列会过期，须与西柚/SIF 现值刷新（本项目实践：16 个月旧快照全词塌 4-92%，见 PK-0021 反方）；
- 下拉框拓词（a-z）产出词噪音大，进词库前需过相关性（PK-0020 的 IQS/同类占比过滤），不要直接投。
