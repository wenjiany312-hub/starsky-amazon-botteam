## 结论（一句话）

Merge（详情页合并）是翻新的替代路径：新建一条与原 listing 细节一致的新 listing → 转 FBA（不必真发货）→ 用后台"如何合并商品详情页面"工具填新 ASIN+待删 ASIN+理由 → 1-2 个工作日合并，旧 ASIN 删除、**库存直接转到新 ASIN**（省去海外仓换标贴标费）。价值：受限 ASIN 免移仓、正常 ASIN 借新品流量提排名、合并变体涨评论。

## 三条硬注意

1. **评论是加总不是择优**：A 五星 + B 一星 = 两条评论三星均分，差评多的旧 ASIN 别合；
2. **反向 Merge 风险**：多数账号"想保留的没保留"——操作前按账号实际行为预期，保留方与删除方都要按可接受结果准备；
3. **范围合规**：仅相同/相似产品（颜色同尺寸不同/配件关系）可合，不能用来删差评。

## 适用 / 不适用

- 适用：受限/滞销 ASIN 清库存、变体重组合并。
- 不适用：评分悬殊的两条链接合并；试图靠 Merge 刷评论。
