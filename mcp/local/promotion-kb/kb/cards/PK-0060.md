## 结论（一句话）

新品定价三选一：**高价+大 Coupon（如 50%）**切入给促销留利润空间、**中价**、**低价**——唯独不要与竞品同价（易被判价格同质化且先被 PK），等排名稳定后再回到对标价。新品 CPC 护栏用三法交叉：①关键词预估均值；②毛利分段（$10 内低价品=毛利 1/5-1/10；$50 中价=1/10-1/15；$100+ 高价=1/15-1/20 甚至 1/30）；③**ACOS=CPC/CR/UOV 反推**：把预期转化率与盈亏平衡 ACOS 代入，得出基础竞价上限，新品出价绝不超过它。

## 演算模板（SRC-3306 实例）

```
利润率 27.5% → 盈亏平衡 ACOS=27%
单次竞价 = 毛利 × 1/10 = $0.7
盈亏平衡所需 CVR = CPC/ACOS盈亏/UOV = 10.37%
```

## Coupon 现实约束

小类目大多数链接长期挂 Coupon 冲单；部分新 ASIN 不能设 Coupon——先出参考价（尽快刷出）再设；source 提示可借低价快速出参考价（注意合规，勿虚假原价）。

## 适用 / 不适用

- 适用：新品立项期定价 + 广告出价护栏设定。
- 不适用：成熟期价格防御（见成熟期卡）。
