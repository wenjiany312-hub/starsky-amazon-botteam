## 结论（一句话）

重推期 Listing 四件套规范：**标题**核心词根进前 5 个单词（用 - / : 分隔）、卖点顺序与五点一致；**五点**每条大写开头、第一条放最大卖点、忌说明书体；**Search Terms** 反查竞品收高频词、标题已用词根不重复埋、词间空格；**图片**主图纯白底实物 ≥85%、分辨率 ≥1600px、附图场景+特性、配视频增信任。

## 操作清单

- [ ] 标题：`核心词 - 差异化卖点 + 规格`，词根前5词
- [ ] 五点：卖点排序=标题顺序；首条=最大卖点
- [ ] ST：竞品反查高频词 − 标题词根 = 埋词池
- [ ] 主图 ≥1600px、白底、85% 占比；副图：场景 → 特性 → 对比；视频有则上
