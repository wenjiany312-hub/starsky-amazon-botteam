## 结论（一句话）

COSMO-LM 用 LLM 从买家行为里挖**深层购物意图**并建全类目知识图谱，流量分发从"关键词相关性"（A9）转向"需求意图匹配"——直接后果是**新品广告冷启动变贵变慢**（初期要 2-5 倍建议竞价才有曝光、预算 4-8 天才烧完、转化延迟），而**语义场景词与自动广告的价值上升**。

## 机制要点

- 与 A9 的区别：深层意图挖掘、知识图谱（18 主要类目）、个性化推荐、常识知识融入搜索、会话推荐等多场景应用；是补充升级而非取代 A9。
- 新品广告三症状：前期曝光不足（即使加价）、预算消耗过慢、转化延迟——影响推广节奏测算。
- 应对（原文建议）：初期竞价≈建议出价×1.5 起步、预算逐步加不一次拉满、缩短广告组时间窗口（如 1 天短窗加速消耗）、多广告组分词/分创意测试、用自动广告跑词再喂手动。
- 自动广告地位上升：AI 接管一半投放把控后，有运营观察到"自动广告数据比手动还要好看"（单方经验）。

## 如何验证（D 级待验证项）

- 2-5 倍竞价/4-8 天预算周期：拿本项目重推新活动（AKO_SP_200ct 系）与 9/11-9/16 零曝光新活动核对"出价×建议竞价倍数 vs 首曝光天数"，用 Ads API 日级数据回归一次。

## 适用 / 不适用

- 适用：重推/新链接预算规划（别按 A9 时代的出价与起量速度排期）；解释"建议竞价内无曝光"的现角。
- 不适用：成熟期链接日常优化（冷启动症状只在初期显著）。

- "2-5 倍建议竞价""4-8 天烧完"是培训方经验值，非官方口径，置信度按 D 级对待；官方只确认 COSMO 是意图理解技术。
