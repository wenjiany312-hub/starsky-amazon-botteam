## 结论（一句话）

老品广告周复盘标准规程：**口径**——SP 看最近 7 天（环比过去 7 天），SB/SBV/SD 看 14 天（归因期）；**方向**——老品以 ACOS 为核心（盈利导向），盈亏平衡 ACOS = 毛利率 −5~10 个百分点（毛利 25% → 平衡点 15-20%）；**例外**——重点推的词只看转化不看 ACOS。加预算：连续 2 周好且曝光超时→按曝光时长给足；一好一差→加 10-20%。广告位：正常不加成（拉高 CPC），加成必须**配合降竞价**且少量多次（+10-20 测试）。

## 操作细则

| 场景 | 动作 |
|---|---|
| 表现好 + 曝光超时（连续2周） | 预算按曝光时长给足 |
| 一好一差 | 预算 +10-20%（预算大加10%，小加15-20%） |
| PP页面点击多且差、顶部无点击 | 降竞价 + 顶部加 bid（控顶部 CPC）；或降竞价给其余位置加 bid |
| 词自然位 P1-2 且稳 | 广告位靠后让自然单（降 bid/去 bid），调完必须复查广告位确实后移 |
| 广告位 P1-4 且自然位也靠前 | 及时降 bid 让位（PK-0005 同源纪律） |
| 竞品秒杀比价 | 关联竞品的广告预算临时调低，秒杀结束调回 |
| 频率红线 | **禁止天天调价/调 bid**（尤其一天多次），毁广告权重 |

## 适用 / 不适用

- 适用：成熟期/重推后段的老品广告周复盘（主推 ASIN D21 起、次主推日常）。
- 不适用：新品冲位期（彼时以量取胜，PK-0005）。
