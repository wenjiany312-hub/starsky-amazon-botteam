## 结论（一句话）

站外放量（FB 折扣组 / Deal 站 / 红人）与站内广告**不同时开**：站外期间关广告（防止广告位数据被站外流量污染、排名不稳）；站外把排名打上去后**再开广告**，出价提到**单件毛利的 1/5**，并用**精准匹配**承接站外带来的搜索热度。

## 操作 / 参数

1. 站外节奏：1-2 周为一轮，隔 1-2 天一场。
2. 站外期间：站内广告暂停（或只留品牌防御词）。
3. 站外结束后：重开广告 → 核心词出价 = 毛利/5 → 精准匹配承接。
4. 避坑（SRC §七）：站外与广告同开=广告排名不稳定，是明确反面做法。

## 适用 / 不适用

- 适用：冲排名窗口需要外部单量杠杆时。
- 不适用：日常稳量期（站外仅作清库存/冲量工具，不常态化）。

## 证据

- SRC-0002 §三策略B + §七 避坑原文。

## 反方 / 已知冲突

- "1/5 毛利出价"为经验系数，CPC 高的类目（>$1.5）按目标 ACoS 反推出价更稳；站外单的转化权重对自然位的作用存在争议（D级推论：出单价权重低于搜索词出单，验证方法：对比站外前后核心词自然位）。
