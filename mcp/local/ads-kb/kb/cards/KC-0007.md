## 结论（一句话，可直接被下游引用）

降 ACoS 有四把刀，按"副作用小→大"排：**① 否词**（源头杜绝无效点击，费时）→ **② 四象限调竞价**（把花费拆成 高点击不出单 / 低点击不出单 / 高 ACoS 出单 / 低 ACoS 出单，按各块花费占比调对应投放的 bid，最直观但必伤流量）→ **③ 缩差活动预算 + 给好转化位置溢价**（能涨销售额但高风险、易空烧）→ **④ 增加低 CPC 的有效投放**（拉低整体 ACoS，需要抓手和结构）。

## 机制 / 原因

ACoS = Σ花费 / Σ销售额。①减分子里的纯浪费；②按花费结构动 bid，效果最快但流量同步下降；③是花费在活动/位置间的再分配，销售额可能涨，但预算集中后一旦位置不转化就是空烧；④通过扩大低成本分母来稀释——要有新的有效投放来源（词库/商品投放），否则无从下手。

## 操作 / 参数

1. 先做 KC-0005 判读确认是"广告表现差"而非"产品力不足"；满足 KC-0006 前提。
2. 否词：客户搜索词报告 → 未出单且点击 > 1.5×出单点击数（经验值）→ 精准/词组否定（分型见 KC-0003）。
3. 四象限：批量操作表拆四块 → 高点击不出单：降 bid 或否；低点击不出单：观察或小降；高 ACoS 出单：降 bid 到合理 ACoS 反推值；低 ACoS 出单：保持或加价拓量。
4. 预算/位置：出单差的活动缩预算给出单好的；转化好的位置（如商品页）加溢价——单次幅度小、盯 7 天。
5. 增加投放：从词库/搜索词报告/商品投放挑 CPC 低于均值且相关的新投放。

## 适用 / 不适用

- 适用：SP 手动与自动活动的日常优化。
- 不适用：新品冲量期（目标不是 ACoS）；SD/SB 位置逻辑不同，溢价规则不套用。

## 反方 / 已知冲突

- "1.5×出单点击数"在低 CVR 类目会误杀（KC-0003 反方）；官方 20 clicks 更保守。
- 四象限按"花费占比"决定优先级，会系统性忽略花费小但 ACoS 极差的长尾投放——补一条"按 ACoS 偏离度"的排序作为交叉。
