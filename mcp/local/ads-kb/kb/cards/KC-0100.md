## 结论（一句话，可直接被下游引用）

官方广告政策快速参考（全球展示广告口径）：**禁止投放**——争议社会/政治内容、粗俗淫秽语言、解酒产品、武器（作为产品）；**限投**——酒类（US/IN/AE/CN 禁、其他站点按 CAP 7.1）、慈善捐赠（文案与版位限制）、电影预告片（按分级限版位）、药品健康美容（按 CAP 7.11）、恐怖内容（禁过度血腥）、暴力/武器内容（仅特定相关情境）；**发布前检查清单**：清晰 CTA（句首大写）、必要披露声明、创意清晰不杂乱、明确品牌与商品、**广告与落地页的价格/优惠声明必须一致**；技术红线：文字不可过小、禁过亮刺眼配色、背景须与白色对比或加 1px 非白边框、站内动画 ≤15 秒、不超字数；Billboard（970×250）CTA 不得做成按钮形状，移动端 CTA 鼓励非强制。

## 机制 / 原因

- 本页是官方 CAP（Acceptance Policies）体系的高频问题速查层：完整禁限清单在 CAP 6.0/7.0——建组前先过速查表，命中限投品类再去查 CAP 对应章节（官方页面自述定位）。

## 操作 / 参数

- 与 KC-0083（品牌创意红线）、KC-0035（SB logo 权利）组成三段合规预检：品类准入 → 创意红线 → 素材技术规范。

## 适用 / 不适用

- 适用：新品类投放前的准入自查（尤其 SD/展示类广告）。
- 不适用：本页自注"非完整政策总览"——最终以 CAP 全文与后台审核为准；SP 商品投放另有资格要求（禁售品等，见 Amazon 政策页）。
