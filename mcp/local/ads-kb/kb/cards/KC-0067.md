## 结论（一句话，可直接被下游引用）

Amazon Ads API（社区指南，C 级）：官方 REST API 覆盖广告控制台大部分功能，**与 SP-API 完全独立**（独立申请/凭证/端点）；可自动化的广告操作包括**批量调预算、调竞价、位置加价、Budget Rules（预算规则）、报表拉取**；社区建议的"双集成"模式＝Ads API + SP-API 打通销售/库存数据，实现**低库存自动暂停广告、按利润率反推竞价上限**——注意这是第三方指南的方案建议，非官方承诺。

## 机制 / 原因

- 对星空系统的意义：所有"自动调价/调预算"类自动化在技术上走 Ads API 是可行的，但本库边界纪律不变——**自动化只到"建议与候选"为止，执行动作停在用户确认**（Skill Guardrail）；此卡供工具层了解能力面，不改变决策边界。

## 操作 / 参数

- 可自动化清单（社区口径）：预算、竞价、Placement 加价、Budget Rules、报表。
- 申请要点（社区口径）：Direct Advertiser 身份最快 1 个工作日审核；必须为 Ads API 单独建 LWA 凭证（与 SP-API 不通用）。

## 适用 / 不适用

- 适用：工具链选型、自动化方案的能力面评估。
- 不适用：作为官方 API 文档引用——细节（端点/限流/政策变化）以官方 Ads API 文档为准，本源仅作线索（C 级）。
