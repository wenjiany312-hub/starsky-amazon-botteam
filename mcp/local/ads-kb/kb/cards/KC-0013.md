## 结论（一句话，可直接被下游引用）

只开了几个广泛组、推不动的老品，翻量按"先冲量再控 ACoS"：**保留表现好的广泛组并加预算、提前否掉材质/属性不相关词**；从出单广泛组里挑 **2 个出单最多的搜索词开 SKAG，竞价给到建议竞价 +20%**；找 **10–20 个同赛道 ASIN**（先投评分评论不如你的）放一个活动，SP + SD 一起投，SD 用 VCPM；SB 里的出单搜索词再投放；属性错误的词集中成一个"错词广告"打广泛。一周翻量的进阶版（ACoS 50%、想冲排名）：Data Driven 把 ACoS 目标设在盈亏线，表现最好的词加投开 **3 个 SKAG**，出单最多的关键词与 ASIN 分别投 **SBV 广泛、按平均 CPC 出价**。红海高垄断类目改用 SKAG 精选 3–5 个更有优势的词 + ASIN 定投 + SBV，而非硬冲大词。

## 机制 / 原因

老品缺的不是数据而是集中度：把预算集中到已验证的少数词（SKAG）与可比的弱竞品 ASIN（关联流量），能在短期内换来订单与排名；SBV 视频位竞争相对小，用平均 CPC 出价性价比高。"错词广告"把属性不符的搜索词集中一处，既保留其偶然转化又不污染主活动。

## 操作 / 参数

1. 基线：保留原 3 个好广泛组，表现好的加预算；否词材质/属性不相关词。
2. SKAG ×2：出单最多的两个搜索词，各自单词单组单活动，bid = 建议竞价 ×1.2。
3. ASIN 定投：10–20 个同赛道 ASIN，先投 rating/review 不如你的；SP 按建议竞价，SD 选 VCPM。
4. SB/SBV：SB 出单词再投放；进阶——出单最多的词和 ASIN 投 SBV 广泛，按平均 CPC。
5. 错词广告：属性错误词集中一个广泛活动。
6. 进阶（一周翻量）：Data Driven 目标 ACoS = 盈亏线；最好的词开 3 个 SKAG。
- 全部经验值（阿波罗，2026-09 抽取）。

## 适用 / 不适用

- 适用：有出单历史、架构过于简单的老品；红海类目。
- 不适用：无出单记录的新品（没有"出单最多的词"可选）；预算 <$50/日（活动数会超出预算承载，见 KC-0010）。

## 反方 / 已知冲突

- "先投评分评论不如你的 ASIN"假设弱竞品页面的访客更易被截流——合理但未验证；类目里若弱竞品流量极小，效果有限。
- Data Driven 为第三方工具功能（阿波罗工具），属 V 级能力宣称，本卡只吸收"把目标 ACoS 设在盈亏线"的原则，不吸收工具效果。
