## 结论（一句话，可直接被下游引用）

单量变化先回答「这些单是怎么来的、哪一层变了」，**定位到端再动手**：流量整体掉还是某个入口掉？点击率掉还是转化率掉？广告流量崩了还是自然排名掉了？拆不出原因之前的加广告、降价、改图都是赌。

## 机制 / 原因（原因树）

- **流量端**：总流量 = 自然 + 广告 + 活动 + 新词。某入口占比下滑先于总单量下滑；「单量没掉、自然占比在掉」是最容易被忽略的早期信号——之后广告要替自然扛量，TACOS 会被抬高。
- **转化端**：同一产品不同入口 / 设备 / 词的 CVR 不同；CTR 高但 CVR 低的词是在花钱买不会买的点击（看价格、评价、页面与词意图是否一致）。
- **利润端**：广告占销售额比例（TACOS）、烧钱不出单的词、仓储 / 物流费异常，决定「单量回来了也不一定赚钱」。

## 操作 / 参数（端 → 该做的动作）

| 定位到的端 | 该做 | 先别做 |
|---|---|---|
| 市场 / 类目整体流量下滑（曝光和竞品一起掉） | 控预算保利润，查季节节点 | 盲目加价抢量 |
| 广告曝光掉（出价 / 预算 / 排位） | 查预算耗尽、竞价、位置 | 改图改文案 |
| 点击率掉（主图 / 价格 / 评价星级 / 竞品动作） | 看搜索结果页竞争、主图、价格 | 加预算 |
| 转化率掉（页面 / 评价 / 价格 / 断货变体） | 查差评、价格、Listing、库存 | 加价加词（放大亏损） |
| 自然占比掉而广告稳 | 查自然排名和核心词位置，用广告撬回核心词 | 全面收缩广告 |
| 利润端（TACOS 升、ACOS 超保本线） | 砍烧钱词、调结构 | 只看 ACOS 砍掉带自然的词 |

## 适用 / 不适用

- 适用：日报发现单量波动、S5 诊断出方案前的第一步；有上一周期对比数据时最有效。
- 不适用：样本太小（单日几单）时不做结论，拉长到 7–14 天对比（见 KC-0011 样本量陷阱）。
