## 结论（一句话，可直接被下游引用）

SB（Sponsored Brands）官方概览：**品牌 logo + 标题 + 视频/生活场景图 + 多产品**的自定义广告，出现在购物结果顶部与中部、商品详情页和首页；**资格**=Brand Registry 卖家、vendor、代理（未注册品牌不能用 SB）；**定向**=关键词/类目/商品；**落地页**=商品详情页/品牌旗舰店/自定义落地页；**计价**=CPC 或 vCPM（每千次可视曝光），无最低花费要求；创意提交后 **72 小时内**完成审核（官方值）。

## 机制 / 原因

- SB 是"品牌级"广告位：一次曝光带多个商品与品牌资产，定位在发现期购物者（与 SP 的单品转化定位互补，官方四种收益：曝光/差异化/流量/忠诚度）。

## 操作 / 参数

- 建组流程（官方）：Create campaign → SB → 设预算（官方建议 ≥$10/天，见 KC-0027）→ 选格式 → 选落地页 → 选定向 → 传创意 → 提交审核（≤72h）。
- 官方建议活动**不设结束日期**、随时可暂停。

## 适用 / 不适用

- 适用：有品牌注册、要多品组合曝光与旗舰店引流的卖家/vendor。
- 不适用：无品牌注册账号（资格不符）；纯单品冲量诉求（用 SP）。

## 反方 / 已知冲突

- 暂无。注意 vCPM 与 CPC 是两种计价模式，账户实际可选范围以后台为准。
