## 结论（一句话，可直接被下游引用）

先比 **产品合理 ACoS vs 类目平均 ACoS** 判产品力（合理 > 类目：若出单 CVR 也高于类目大词 CVR 则是出价过高，若 CVR 低 20%+ 则是产品力不足别冲前排；合理 < 类目：产品力强可拓流），再比 **产品实际 ACoS vs 过去 7 天合理 ACoS**（±15% 内正常；远高 → 需优化；偏低 → CPC 偏低流量被挤压，ACoS 可接受则拓流）。

## 机制 / 原因

三条基线只有两两对比才有意义：合理与类目之差隔离了"产品 vs 市场"，实际与合理之差隔离了"现在的出价/流量 vs 产品应得"。把"ACoS 高"拆成产品力问题还是出价问题，动作完全不同（前者改 Listing/定价，后者调 bid）。

## 操作 / 参数

| 场景 | 判定 | 动作方向 |
|---|---|---|
| 合理 > 类目 且 出单 CVR > 类目大词 CVR | Bid 出价过高 | 降 bid / 换位置 |
| 合理 > 类目 且 出单 CVR ≪ 类目 CVR（低 20%+） | 产品竞争力不足 | 不冲前排；先修 Listing/价格/评论 |
| 合理 < 类目 | 产品力高于市场 | ACoS 可接受则拓流 |
| 实际 ≈ 合理 ×(1±15%) | 正常 | 维持，按节奏复盘 |
| 实际 ≫ 合理 | 广告表现差 | 进入 KC-0007 四种调整 |
| 实际 < 合理 | CPC 偏低、流量被挤压 | ACoS 可接受则加价拓流 |

全部阈值为**经验值**（阿波罗，2026-09 抽取），按类目校准。

## 适用 / 不适用

- 适用：满足 KC-0006 前提（日出 ≥5 单、架构稳定）的活动。
- 不适用：新品期样本不足；SB/SD 品牌曝光目标活动（ACoS 不是主指标）。

## 反方 / 已知冲突

- ±15% 与 20% 是课程经验阈值，无统计推导；高波动类目（低 CVR、高客单）应放宽窗口到 14–30 天（见 KC-0006）。
