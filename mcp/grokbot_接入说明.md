# 数据工具接入说明（Grok Bot）

| 工具 | 谁用 | 是否必需 | 怎么接 |
|---|---|---|---|
| SIF | 选品侦察员、文案算法师、广告优化师 | 推荐 | 有连接器或插件就接；密钥用安全密钥卡填 |
| Sorftime | 选品侦察员、风控官、广告优化师 | 可选 | 同上 |
| 西柚 / 卖家精灵 | 选品侦察员、文案算法师、广告优化师 | 可选 | 同上 |
| 1688 | 仓管物流 | 必需 | **装在云电脑上**：运行 `{{KIT}}/mcp/local/install_grokbot.sh`，再以「命令」注册为自定义 MCP `1688_scraper`；第一次找货要登录时老板接管电脑扫码。建议打开 Settings → Computer → Route traffic through this computer |
| 知识库（选品 / 广告 / 促销） | 选品侦察员、风控官、财务管家、广告优化师、复盘分析师 | 必需 | 免安装：以「命令」注册为自定义 MCP（install_grokbot.sh 最后会打印命令）；不通时用 `amazon-kb-query` 命令行 |
| SP-API / Ads API | 运营总监（经数据底座） | 需要时 | 不在 Grok 里注册。客户在自己电脑装好数据底座并授权后，上架、A+、品牌故事、广告改动都由运营总监跑命令、老板在审核报告里确认推送 |

规则：
1. 密钥不进对话、不进文件；Bot 让你把密钥贴进聊天，就拒绝
2. 不要把密钥放在 `{{WORK}}/` 下：云电脑上的文件所有 Bot 都能看到
3. 某个工具没接上，对应角色改用页面信号或你导出的文件，数据等级标「页面信号」
