## 二、授权到底锁什么
Bot Team 装进 Bot 平台之后，提示词和技能都是明文。所以授权锁的是：
1. **安装器**：没有有效授权，安装器不解密、不写入平台目录
2. **更新**：会员期内能拉新版；试用版只能装指定版本
3. **水印**：每个安装包写入授权 ID（`license/watermark.txt` + 每个 soul.md 末尾一行注释），泄露时能追查

锁不住的：已经装进平台的内容被复制。这个靠水印追查和使用条款解决。

## 三、安装流程
```
1. 买家从 GitHub 发行页下载安装器（**Mac、Windows 各一个**，同一份加密业务包；设备码绑买家自己的电脑，不绑 Grok 云电脑）
2. 运行「申请授权」→ 显示 32 位本机申请码
3. 买家把申请码 + 要装的平台发给你
4. 你在授权登记助手选「星空亚马逊 Bot Team」→ 填申请码、权益类型、到期日、版本档、平台 → 签发 SKYBT1. 码
   → 同时写入本机台账和飞书多维表格（第四节）
5. 买家运行「安装与更新」→ 粘贴授权码 → 校验通过才继续
6. 选平台：
   - OpenBot / StarSky：安装器把技能、知识库、本地 MCP、模板写进平台目录，再生成给运营总监的 BOOTSTRAP 口令
   - Grok Bot：生成上传包（zip），买家发给 Primary Bot
7. 运营总监按 BOOTSTRAP.md 自己搭团队，交回执
```
更新：会员期内运行「检查新版」→ 用会员凭证拉新版 → 升级模式（不删除、不覆盖买家自己的台账和产物）。

## 六、老板已定（2026-11-10）：授权不锁 Grok 账号
- 授权码只绑**运行安装器的电脑**；Grok 账号不做技术绑定（同一账号多设备登录本来就共用一台云电脑）
- 约束靠：**使用条款**（`license/使用条款.md`：一张授权 = 一台电脑 + 一个 Grok 账号）+ **水印**追查 + **更新只给登记过的授权**
- 签码时在飞书表「备注」里记客户的 **Grok 账号邮箱**，方便售后核对；以后需要再加独立字段
- 不做「云电脑码」软绑定（只能卡更新、卡不住已装内容，绕过成本低）


## 七、老板已定（2026-11-10 晚）：Grok 版改成「云电脑码」（rc11，只做第 1 层）
- 安装器改在 Grok 云电脑上运行，授权码绑**云电脑**（= 一个 Grok 账号），不再绑本地电脑；本地不再生成上传包
- 前提：云电脑指纹测试 3 次（今天 / 明天 / Grok 重启后）找到稳定标识；算法见 `13_交给Claude_rc11云电脑码.md` 第三节
- 第 2 层（知识库、报告脚本运行时解密）、第 3 层（远程服务）先不做；到期不回收已装内容
- 本地电脑码只留给旗舰版终端、OpenBot、StarSky
- 上面第六节「授权码只绑运行安装器的电脑」到 rc11 作废


## 八、老板已定（2026-11-10 v2）：设备码 + 云电脑码双层授权
- 一个授权编号 = 一台本地电脑（设备码，买家身份）+ 一台当前云电脑（云电脑码，运行位置）+ 服务期内更新
- 运行时只核对云电脑码；设备码在签码、换绑时由老板核对
- 换绑：同一授权编号、绑定号 +1、到期日不变；服务期（一年）内含 2 次免费，之后 ¥200 / 次；Grok 自己重建云电脑（账号没变）不扣
- 换绑后旧云电脑不再生成会员更新凭证；已装内容不回收
- 详细规格：`13_交给Claude_rc11云电脑码.md`；上面第七节由本节替换
