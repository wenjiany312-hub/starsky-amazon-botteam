## 一、为什么要改

**问题**：整套图的叠字不统一 —— 字体、字号、颜色各图都有出入，做不出精致感。

**病根**：GPT-image-2 / Nano Banana 渲染文字，是**每次重新臆造一遍像素**。
它没有字体文件、没有样式表、没有跨图记忆。在 Prompt 里写
`elegant sans-serif, medium weight, sentence case`，模型每次都会给你一个
「看起来像那么回事」的不同字体。七张图就是七次独立幻觉。

**这不是提示词写得不够细，是这类模型压根不提供「一致」这个能力。**
在提示词里继续加规则，到不了精致。

### 实测证据（2026-08-06 run，宠物雨衣）

| | 02_v3 | 03_v3 | 04_v3 |
|---|---|---|---|
| 标题字体 | 一种粗黑体 | 另一种 | 第三种 |
| 标题颜色 | 近黑 | 近黑 | **藏青** |
| 标题落位 | 顶部约 6% | 约 15% | 约 10% |
| 副标处理 | 全大写灰标签 | 灰色细体数字 | 句式正文 |
| 产品主色 | 饱和亮黄 | **发灰的浅黄** | 饱和亮黄 |

04 还凭空引入了一整套藏青色块表格，其余六张都没有这个颜色。
同时 01/02/03/04/06 全部跑到 **v3** —— 五张图三轮重生成，只因为改字得整图重来。

## 二、两层分离

```
第一层  底图 plate    AI 出，非确定性   产品 + 场景 + 光线，⛔ 一个字都不许有
第二层  叠字 overlay  代码画，确定性     全部样式来自 视觉样式令牌.yaml
```

**效果**：整套图的文字像素级一致，是构造出来的，不是碰运气碰出来的。

**附带好处**：改错字不用重生成。改 YAML 重跑两秒，产品像素一个不动。
v2/v3 那种 churn 直接消失。

## 四、可选叠字模式：用户主动要求时出「无字底图」

### ⛔ 仅对已明确选择叠字模式的任务生效；R03 默认图文一次生成

### 该可选模式的规则

1. **Prompt 里不得再要求模型渲染任何文字**（标题、参数、标签、徽章、底栏，全部不许）
2. **必须显式排除文字**：negative 段落写 `no text, no lettering, no numbers, no labels, no watermark, no logo`
3. **必须要求留出负空间**，位置对应 `overlay_tasks.yaml` 里该图用到的版式积木

### 替换掉的旧段落

| 旧 | 新 |
|---|---|
| `[EDITORIAL COPY INTEGRATION]` 要求模型渲染文案 | `[NEGATIVE SPACE RESERVATION]` 只要求留白 |
| `[SPEC OVERLAY INTEGRATION]` 要求模型渲染参数标注 | `[SPEC ZONE RESERVATION]` 只要求底部留干净带状区 |

### 新段落写法

**A 档 `editorial_dtc`：**

```text
[NEGATIVE SPACE RESERVATION] Reserve a clean, uncluttered negative space area
in the upper-left third of the frame — a plain wall, out-of-focus air, or quiet
surface. No product parts, no props, and no strong texture in that area; text
will be composited there in post-production. Keep the area tonally even so
dark type reads cleanly on it.
CRITICAL: render NO text, letters, numbers, labels, badges, or bars anywhere
in the image.
```

**B 档 `spec_dense`：**

```text
[SPEC ZONE RESERVATION] Keep the bottom 15% of the frame clean and tonally
even — a flat surface or plain backdrop with no product parts and no props.
A specification bar will be composited there in post-production. Position the
product so that every part requiring annotation is fully visible and
unobstructed above that zone.
CRITICAL: render NO text, letters, numbers, dimension lines, labels, or
information bars anywhere in the image.
```

### 底图输出路径

```
S3_视觉板块/amazon-listing-image-designer/visuals/listing/plates/IMGxx_plate_v1.png
```

⛔ 底图不是交付物，**不要**直接给客户/学员当成图。

## 五、`overlay_tasks.yaml` 怎么写

样式引用令牌（`style`），落位引用积木（`block`），AI 只负责 `text` 字段。
⛔ **不允许在任务表里自由给坐标、自由给字号、自由给颜色值。**

完整字段与示例见 `../../../templates/overlay_tasks.example.yaml`。最小形态：

```yaml
- item_id: IMG02
  canvas: secondary
  profile: editorial_dtc
  plate: ../visuals/listing/plates/IMG02_plate_v1.png
  output: ../visuals/listing/IMG02_v1.png
  buyer_question_id: BQ-03        # 存在 07A 蓝图时必填，保持可回溯
  source_evidence_ids: [EV-11]
  overlays:
    - block: headline_tl
      style: h1
      text: "High Collar Two-Leg Poncho"
```

**文字内容仍然受 `../../../templates/consumer_visible_copy_contract.md` 四条硬规则管辖**
（R1 禁内部备注｜R2 典型性闸门｜R3 benefit gate｜R4 禁写清单不连坐）。
换了载体不改变它是文案的事实 —— 自检照旧写进 run log。

## 六、渲染与闸门

```bash
python <home>/scripts/叠字渲染器.py {产品根}/S3_视觉板块/amazon-listing-image-designer/overlay_tasks.yaml
```

| 参数 | 作用 |
|---|---|
| `--check` | 只过闸门不出图，写 Prompt 阶段就能先验 |
| `--item IMG03` | 只跑一张 |

**五道闸门**：

1. 主图不得叠字（亚马逊主图规则）
2. 档位样式与块数（A 档最多 2 块、不许 spec 样式、不许强调色…）
3. 缩略图可读性（缩到 500px 后字号不得低于 11px）
4. 安全区（文字不得越过画布边缘 6%）
5. 底图比例与画布一致（差 >1% 判失败 —— 轻微拉伸把产品压变形，肉眼不易察觉，
   实测就靠这道闸门拦下过一张被压扁的主图）

**退出码**：`0` 全通过｜`1` 有条目未过（成图落到 `_未通过/`，正式目录不被覆盖）｜`2` 文件本身有问题

运行日志写到 `S3_视觉板块/amazon-listing-image-designer/叠字渲染日志.yaml`，含实际用到的字体文件与逐条闸门结果。

## 七、做不了的，老实说

- **带引线的部件标注**（callout line 指向产品某个部位）：引线终点取决于底图里
  产品的实际像素位置，每张都不一样，脚本算不出来。这类在网页端 / Codex App 里人工改，
  或让出图环节直接把标注画进底图（但那样又回到不一致，慎用）。
- **产品颜色漂移**：本契约只解决文字层。产品主色在各图之间漂（实测发生过）
  要靠抠图合成解决 —— 产品像素直接来自原始照片，不让模型重画。这是下一步。
- **字体观感**：当前默认 Arial，能用但不高级。放一份 SIL OFL 授权的
  Inter / Archivo / Manrope 到 `<home>/assets/fonts/`，
  改 `visual_style_tokens.yaml` 的 `fonts` 段即可全线换字体，可合法随学员包分发。

## 八、老 run 怎么办

已经出好的 run **不用回炉**。本契约从下一条产品线开始执行。
需要改老 run 的某张图时，可以单独为那张图做无字底图 + 叠字，
但同一套 7 图不要一半旧一半新 —— 那比全旧还乱。
