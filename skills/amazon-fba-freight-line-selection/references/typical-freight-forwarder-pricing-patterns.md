# 典型货代报价表结构与字段含义

> 本文件总结 2026-07 接触过的瓴派供应链（TCD）"TCD 最强线路 VIP 成本价 Eric-20260716 生效" 报价表结构，以及行业内常见的同类 xlsx 模式。下次遇到新货代的报价表时，先用本文件做模式匹配，能大幅缩短解析时间。

---

## 1. 典型多 sheet 结构（瓴派 / TCD 模板）

```
目录
价格快速导航
K13全美限时达
K16洛杉矶快线
D20洛杉矶
M25洛杉矶
K25纽约快线
K21以星带拖架          ← 注意：目录里未必出现，可能是子线/特惠线
D35纽约
美国UPS偏远地区邮编
美国FEDEX偏远地区邮编
美国亚马逊仓库地址
导航
澳洲FBA海派-包税
```

每个 sheet 都有大量**横向合并单元格**（标题/价格表头跨多列），必须先 `resolve_merged()` 再 `iter_rows`，否则关键字段会变 None。

---

## 2. 关键 sheet 的语义

| Sheet 名 | 作用 | 关键字段 |
|---|---|---|
| 目录 | 速览所有线路的"卸货港 + 船司" | 序号 / 名称 / 卸货港 / 船司 / 优势特色 |
| 价格快速导航 | 兜底报价（按邮编分区的统一价） | 邮编分区 / 深圳/广州/宁波/义乌交货 / 12-50KG / 50.1+ |
| Kxx / Dxx / Mxx | 单条线路的详细报价（**最有价值**） | 海派 + 海卡两套，列宽常 14-22 列 |
| 美国亚马逊仓库地址 | FBA 仓库代码 → 地址 → 邮编 → 州 | 用于交叉验证邮编 |
| 导航 | **FBA 仓库代码 → 邮编 → 邮编首位 → 分区** | **核心定位表**，每个 FBA 仓一行 |
| 美国UPS/FEDEX偏远地区邮编 | 偏远邮编表（按等级：偏远 / 超级偏远 / 极偏远 / 禁运） | 决定 +RMB35/箱 的附加费 |

## 3. 关键字段速查

### 3.1 渠道代码前缀
- **K = 快线**（如 K13、K16、K25）：高时效，运价较贵
- **D = 王牌路线**（如 D20、D35、D23）：中等时效与价格，TCD 主推
- **M = 慢线**（如 M25）：低时效，运价最低
- **数字 = 开船到拆柜总时长**（K13 = 13 天）

### 3.2 后端派送方式
- **海派（海运+快递派送）**：卸港到 FBA 仓走 FedEx / UPS，整柜到门时效快 14-30 天
- **海卡（海运+卡车 LTL 派送）**：卸港到 FBA 仓走 LTL 卡车 / 整车，**含"组合 X"对应到具体 FBA 仓**，运价便宜但时效长 25-40 天
- **快递**：直发，时效最短 7-10 天

### 3.3 计费规则
- 海派：1 CBM = 167 KG，最低计费重 12 KG/箱
- 海卡包税：1 CBM = 167 KG（包税）；1 CBM = 363 KG（不包税）
- 托盘 / 木架 / 木箱超大件：计费系数按入仓数据 × 1.1

### 3.4 报价列结构
通常按 4 个出货地 × 2 个重量段 × 2 个税率（包税/不包税）= 16 列：
```
深圳交货价格 | 广州交货价格 | 宁波交货价格 | 义乌交货价格
12-50KG | 50.1+
海卡包税 | 海卡不包税
```

### 3.5 必查的附加费
- 包税产品附加费：纺织 +1，电子 +1，高风险 +1，汽配 +2（单位 RMB/kg）
- 偏远地址附加费：RMB 35/箱
- 多品名清关费：每票超过 5 个品名后每个 +RMB 30
- 报关费：深圳/广州 RMB 150/票；上海/宁波/厦门 RMB 100/票
- 商检费：常规 200 RMB/票，敏感品（猫砂/护肤品/化妆品）800-1800 RMB/票
- 超长费：单边 120-150 cm 加 RMB 200/CBM 或 RMB 1.5/kg
- 超重费：单箱 35-70 kg 加 RMB 10/箱
- UPS 超长超重：单件 > 22.5 kg 加 RMB 160/件

### 3.6 截关/开船周期（船期代码）
- **6 截 3 开**：截关日是开船前第 6 天，开船后第 3 天可装柜提货
- **4 截 1 开**：更紧凑，运价通常更便宜
- **3 截 1 开**：D35 纽约线专用

## 4. 其他常见货代模式（速记）

| 货代 | 报价表常见 sheet 名模式 | 备注 |
|---|---|---|
| 瓴派供应链 TCD | 见上 | 2026-07 接触 |
| 联运通 LYT | "渠道总览"/"分区价目"/"敏感货说明" | 美线主力 |
| 顺友 SY | "线路大全"/"美西表"/"美东表" | 偏向小货 |
| 易达通 YDT | "美线报价-海派"/"美线报价-海卡" | 一个美线合并一个大 sheet |
| 拓普 TOP | "Channel List"/"US-West"/"US-East" | 偏英文 |

**判断是否为"合并报价"模式**：
- 单一 sheet 横向超 20 列 + 多个 sheet = TCD 风格（每条线一 sheet）
- 单 sheet 行数 100+ + 列数 5-8 = 合并风格（按 sheet 内分组）

## 5. 解析时常见的坑

1. **价格列里有日期型数字**（如 `5.84851851851852`）—— openpyxl 读出来是 float，不要 round，否则 +0.5 量级误差
2. **合并单元格被错误填值**——某些货代用合并来表示"适用范围"而不是标题，要按行号逐行解读
3. **海卡表的"组合 X"概念**——D20 / M25 把美西仓按卡车距离分了"组合一/二/三/..."，IUSF 通常落在"组合七"
4. **K21 标注"暂未开始"**——表内有数据但实际上线路未开通，排除
5. **导航 sheet 的邮编列被合并**——必须先用 `resolve_merged` 再读，否则关键邮编会显示为 None

## 6. 推荐的解析 SOP

1. 用 `scripts/inspect_xlsx.py` 把所有 sheet 落盘成 TSV 到 `_raw/`
2. 人工扫"目录"sheet 得到**线路清单**（卸货港 + 船司）
3. 锁定"导航"sheet 查目的仓邮编→分区
4. 对每个候选 sheet 找"分区"列（"美中邮编 4-7"）或"目的地"列（"组合七 IUSF"）
5. 把每条线路的"报价 + 时效"抽出来做矩阵
6. 至少输三方案对比（最快 / 综合最优 / 最便宜）

---

## 7. 一句话总结

> **货代报价表 = 多 sheet 横向合并 xlsx + 邮编分区 + 时效字段**。解析关键在 `resolve_merged` 和"导航"sheet 的邮编反查，不要被"价格快速导航"sheet 的简化报价误导——它丢掉了所有针对性特价（如"组合七 IUSF"）。
