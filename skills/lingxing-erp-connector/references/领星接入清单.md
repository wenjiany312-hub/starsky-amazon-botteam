# 领星 OpenAPI 接入清单

这份清单用于首次配置 `lingxing-erp-connector`。公开分享版不包含任何真实凭据,需要使用者在本地自行填写 `lingxing_config.yaml`。

## 第 1 步:开通开放接口

用超级管理员账号登录领星 ERP:

1. 设置 -> 业务配置 -> 开放接口
2. 填写接收通知的邮箱并进入开放后台
3. 在 API 信息页复制企业 AppID 和 AppSecret

## 第 2 步:配置 IP 白名单

领星 OpenAPI 会校验出口 IP。请查询当前机器访问领星时使用的直连出口 IP,再填入开放后台白名单。

推荐在 Windows PowerShell 执行:

```powershell
curl.exe --noproxy "*" http://ip.3322.net
```

如果电脑开了分流代理,不要直接使用国外 IP 查询站点作为依据,否则可能查到代理出口。家用宽带通常是动态 IP,如果之前能用、后来突然报 IP 不在白名单,先重新查询出口 IP 并更新白名单。

## 第 3 步:填写配置

复制模板:

```powershell
Copy-Item .\references\lingxing_config模板.yaml "$HOME\.starsky-codex\config\lingxing_config.yaml"   # Mac：cp references/lingxing_config模板.yaml ~/.starsky-codex/config/lingxing_config.yaml
```

填写:

```yaml
lingxing:
  app_id: "ak_xxxxxxxxxxxxx"
  app_secret: "xxxxxxxxxxxxxxx"
  base_url: "https://openapi.lingxing.com"
```

注意:填好后的 `lingxing_config.yaml` 含凭据,不得进入公开仓库、分享包、课程包、报告或聊天消息。

## 第 4 步:冒烟测试

```powershell
python .\scripts\lingxing_client.py --smoke
```

成功标志:

- 打印 access token 获取成功
- 打印店铺列表
- 每个店铺能看到 `sid`

然后把要巡检的店铺 sid 填进 `lingxing_config.yaml`:

```yaml
stores:
  - sid: 123
    nickname: "美国站主店"
    marketplace: "US"
    patrol: true
```

## 常见报错

| 报错 | 常见原因 | 处理 |
|:--|:--|:--|
| 取 token 失败 | AppID/AppSecret 错误或有空格 | 重新复制凭据,检查首尾空格 |
| IP 不在白名单 / access denied | 出口 IP 未加入白名单或已变化 | 重新查询直连出口 IP 并更新白名单 |
| 签名不正确 | 领星签名规则变化或凭据复制不完整 | 核对官方 OpenAPI 文档和 AppID 长度 |
| 3001008 | 接口限流 | 等 1-2 分钟后重试,自动化任务增加间隔 |
| 时间不能为空 | 销量接口缺 `event_date` | 补 `{"sid":123,"event_date":"YYYY-MM-DD"}` |
| orders 500 | 订单接口缺日期范围或分页参数 | 补 `start_date`、`end_date`、`offset`、`length` |
