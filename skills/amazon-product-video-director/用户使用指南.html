01

这个 Skill 做什么

本 Skill 是亚马逊产品短视频导演。它不替你「一键成片」，而是产出：分镜脚本、分镜垫图 Prompt/实图、以及按平台分流的视频生成包。v3.0 起二选一：Grok Imagine（英文 image-to-video + video_production_v2 自包含包）或即梦（中文 @引用投喂包）。

两段式交付（核心设计，两平台相同）：

阶段产出你用什么工具
第一段 · 静态分镜关键帧垫图GPT-image-2 / Nano Banana / Grok 静图 / 复用 Listing·A+ 图
第二段 · 动态5–8 段短视频 clipGrok Imagine 或 即梦 Seedance
第三段 · 合成完整 15–45s 视频ffmpeg / 剪映 + 后期字幕

平台怎么选：Premium A+、防变形量产、可走 API → 选 Grok。国内主图竖版、剪映生态 → 选 即梦。对话开始 Agent 会强制问一次。

唯一视频入口：本 Skill 直接产出 Premium A+、Listing 与 SBV 可用的分镜及 Grok video_production_v2；工具包不再依赖其他 A+ 视频 Skill。

参考结构：以本 Skill 输出的 S3_视觉板块/amazon-product-video-director/14_产品视频分镜.md 与 S3_视觉板块/amazon-product-video-director/video_production_v2/ 为准。

02

什么时候用

帮我做产品视频分镜 + 即梦提示词
根据产品图和卖点出 30s 主图视频方案
生成分镜垫图 prompt，给我即梦能用的提示词
继续做产品视频（05 图 brief 完成后）
Listing 短视频脚本
SBV 广告视频创意

在 Codex 对话里说出上面任意一句，Agent 会自动加载本 Skill。

最佳时机：已完成市场调研、文案、Listing 图片 brief（步骤 05）之后。有 1688 高清垫图时效果远好于只有模糊供应商图。

04

完整操作流程（跟着做就行）

0
PHASE 0

产品认知 + 素材盘点

Agent 读取你的报告文件，建立「产品结构真值表」，输出素材盘点表和产品认知摘要。

  • 核对产品外观、卖点、合规红线是否正确
  • 确认垫图路径能访问
你说「信息无误，继续」或指出需要修改的地方
1
PHASE 1

确认视频参数

Agent 会问你几个选择题：

  • 视频类型：转化型 / 展示型 / 种草型 / 讲解型
  • 时长：15s / 30s / 45s
  • 画幅：9:16 或 16:9
  • 垫图生图模型：A. GPT-image-2（默认）/ B. Nano Banana 2
你说「30s 转化型，9:16，模型 A」
2
PHASE 2

分镜规划

Agent 按时长自动拆镜头。30s 转化型默认 5 段 × 6s：

  • S01 场景引入 → S02 痛点 → S03 产品出场 → S04 使用演示 → S05 hero 定格
3
PHASE 3

输出分镜 + 提示词包（核心交付）

此阶段不生成视频，只出方案和 Prompt。你会收到 5 个文件（见第 06 节）。

你说审阅分镜，满意后进入下一步；不满意指出要改的镜头
4
PHASE 4

生成分镜垫图（可选，二选一）

选项 1：让 Agent 基于垫图 + Prompt 生成 video_storyboards/ 目录下的分镜图。

选项 2：直接复用 S3_视觉板块/amazon-listing-image-designer/visuals/ 里已有的 Listing 场景图/功能图作首帧（更省钱）。

你说「生成分镜垫图」或「用 visuals 图 2 和图 5 作首帧，跳过生图」
5
PHASE 5

即梦生成 + 剪辑合成

你亲自操作即梦（Agent 不代替你点即梦）。按第 05 节逐步投喂，生成 5 段 clip 后用剪映拼接。

完整对话示例（复制改产品名即用）
帮我做这款【宠物饮水机】的 30s 主图视频，用即梦生成。
产品根：{Codex 打开的产品文件夹}（上游报告在 S1_选品板块\ 与 S2_文案板块\ 各 Skill 夹里）
视频类型：转化型，画幅 9:16，垫图模型 A。
05

即梦实操步骤（手把手）

打开 Skill 产出的 jimeng_upload_manifest.yaml 和 jimeng_web_clip_prompts.txt，按以下步骤操作：

1

打开即梦 → 选择「图生视频」

每段单独生成，不要试图一条 prompt 做完整 30s。30s 视频 = 5 次独立生成，每次 5–6s。

2

按 manifest 上传图片

每段最多上传 1 张首帧 + 1 张结构锚点（1688 主图）。例如 C01 段：上传 video_storyboards/S01_hook.jpg 作首帧，上传 S3_视觉板块/amazon-listing-image-designer/产品垫图/main_01.jpg 作结构参考。

3

复制对应段的提示词

从 jimeng_web_clip_prompts.txt 找到 === C01 === 段落，整段复制到即梦。提示词里已有 @图片1 作为首帧 等引用说明。

4

设置时长 5–6s，生成

逐段生成，每段生成完先验片：产品颜色、部件数量、比例是否正确。不合格只重做该段。

5

重复 C02–C05，剪映拼接

5 段 clip 导入剪映/CapCut，按 S01→S05 顺序排列。字幕从分镜表的 overlay_text 字段后期叠加（不要写进即梦 prompt）。

即梦单段提示词示例（C01 钩子段）
@图片1 作为首帧，产品外观 100% 参考 @图片2。

0–2秒：固定机位，产品占画面中心 30%，柔和自然光从左侧打入。
2–5秒：慢推镜头，手部从画面右侧轻触产品，展示核心交互。
5–6秒：产品 hero 定格，浅景深。

运镜：慢推，禁止环绕产品。
音效：轻柔环境白噪音 + 轻微产品交互声。
风格：现代美式 DTC 产品广告，电影级质感。
产品结构严格锁定，禁止变形、拉伸、增删部件。
即梦变形防控（必看）
  • ✕ 不要一条 30s prompt + 8 张图一次性生成（产品极易变形）
  • ✕ 不要用环绕/orbit 运镜拍产品
  • ✕ 不要上传清晰真人正脸（会被拦截）
  • ✓ 每段 1 首帧 + 1 结构锚点，相机尽量静态或慢推
  • ✓ 变形严重时：该段改 Listing 静图 Ken Burns，或手机实拍 3–6s
05b

Grok Imagine 实操（v3 推荐产线）

当你对 Agent 说「用 Grok Imagine」时，Skill 会组装自包含包 S3_视觉板块/amazon-product-video-director/video_production_v2/，而不是即梦 @引用文件。

对话里怎么说：

示例触发句
帮我做 Premium A+ 产品视频，平台选 Grok Imagine，时长约 42s，16:9。
读取本案例目录的 product_profile、A+ brief、1688 垫图和 aplus_visuals。
步骤谁做做什么
1Codex分镜 + 英文 clip prompt + 组装 S3_视觉板块/amazon-product-video-director/video_production_v2/
2Codex / 生图模型生成 video_storyboards/，同步到 images/clip_XX/
3Grok逐段 image-to-video（高风险段 primary+结构锚点）
4本地ffmpeg / concat_final.py 拼成片，字幕后期加

三条高效路径（写在包内 FAST_PATH / kit）：

路径手动上传做法
A 混合快路径 ⭐约 2 次低风险段静图 Ken Burns；只让 Grok 做动作段 02/03
B API 一键0 次XAI_API_KEY + batch_grok_video_api.py --concat
C Grok Agent0 次*打开包目录，发送 START.txt 内容（*需 Agent 能读本地盘）
Grok 变形防控（必看）
  • ✕ 禁止一次上传全部 8–14 张分镜做一条长 reference_to_video
  • ✕ 禁止动作段不带 1688/结构锚点
  • ✕ 禁止 orbit 环绕产品
  • ✓ 一段一传；high 段多生成 2–3 条选优
  • ✓ 产品保真锁写进每段英文 Prompt（臂数、直径等可量化）

07

省钱省时间技巧

技巧怎么做省什么
复用 Listing 7 图 图 2 场景图 → 即梦首帧；图 5 功能图 → 演示段首帧 跳过 GPT-image-2 生图费用
变体共用母片 同系列颜色款只换首帧或字幕，不重做全片 即梦生成次数 ×N → ×1
长尾 SKU 用静图视频 Listing 场景图 + Ken Burns 5–10s，不进即梦 零 AI 视频成本
季节品母片 + 后期叠字 节日元素（雪花/南瓜）后期加，不写进 prompt 每年不用重做
复杂动作段实拍 折叠/按压等高风险镜头，手机拍 3–6s 插入 避免反复重做变形片段
08

常见问题

Q：只有产品图，没有完整报告文件，能用吗？
可以。直接告诉 Agent 产品名称、卖点、图片路径、视频时长和画幅即可。但效果不如有 1688 垫图 + 文案 + 05 图 brief 的完整流程。
Q：即梦生成后产品变形了怎么办？
只重做变形的那一段（不要重做全片）。检查是否上传了结构锚点图（1688 主图）。仍变形则该段降级为 Listing 静图 Ken Burns 或手机实拍。详见 references/jimeng-seedance-constraints.md。
Q：字幕和促销信息怎么加？
全部后期在剪映叠加。分镜表 overlay_text 字段有字幕建议，但不要写进即梦 prompt（避免 AI 乱生成文字）。
Q：16:9 横版和 9:16 竖版怎么选？
9:16 用于主图视频位、TikTok/Reels 广告；16:9 用于 SBV 品牌视频广告、A+ 横版模块。在 Phase 1 告诉 Agent 即可，会影响垫图尺寸和即梦画幅。
Q：05 图 brief 还没做，能先做视频吗？
可以独立运行，但建议先完成 05 图 brief。有 7 图方案后，视频风格才能和 Listing 视觉统一，且可直接复用场景图省掉垫图生成。
Q：Premium A+ 视频也从这里做吗？
是。本 Skill 是工具包唯一视频入口，覆盖 Listing、SBV、种草和 Premium A+ 演示片，输出 Grok 或即梦投喂包。
Q：Grok 和即梦选哪个？
Grok Imagine：A+ 横版、英文市场、防变形分段产线、可 API 批量。即梦：主图竖版、国内工具与剪映习惯。不要在同一 clip 文件里混写两套语法。
Q：Grok 一次上传所有分镜图可以吗？
不可以。案例 v1 证明会导致产品变形。必须一段一传；动作段加 1688/结构锚点。详见 references/grok-imagine-constraints.md。
