# 亚马逊 AI 人物标记技能 v1.0

> 本技能的规则以 **2026-11-02 核对过的亚马逊官方公告** 为准。如果旧的参考文件（比如 2026-06-10 快照里写的"不需要 AI 标识，只做内部留痕"）和本技能冲突，**一律按本技能执行**。
> 距离 policy_snapshot 超过 review_days（30 天）时，执行前先提醒老板重新核对亚马逊帮助页面。

## 一、规则是什么（官方要点）

1. **什么时候要标**：图片或视频里有**写实的、AI 生成的人**，在添加到 Listing 或 A+ 之前，必须先打上元数据标记。范围是**亚马逊全球所有站点**。
2. **怎么标**：用支持 IPTC 的元数据编辑器，在文件的 **XMP `dc:subject`** 字段里加上关键词 **`contains-synthetic-performer`**，拼写必须一字不差。
3. **标了之后**：亚马逊读到这个标记，会在详情页给买家显示"含 AI 生成人物"的提示，**卖家不用自己在图上加字**。
4. **以下情况不用标**：
   - 只有**真人**（即使用 AI 修过图，也算真人）
   - 只有电影、电视、游戏等作品里的角色（比如海报、游戏封面）
   - 画面里**没有人**
   - 有人物，但**不是写实风格**（插画、卡通）
5. **为什么有这条规则**：美国纽约州的 AI 广告披露法（NY GBL §396-b）要求披露"合成表演者"，罚款由广告主承担，在亚马逊上也就是卖家。
6. **不标的后果**：图片可能被删除。如果被删的是主图，又没有合规的替代图，整个 ASIN 可能被搜索屏蔽。**之前已经上传的内容也要补标。**

## 二、团队从严执行的口径（比官方更严）

| 情况 | 团队怎么处理 | 原因 |
|---|---|---|
| AI 生成的全身或半身写实人物 | ✅ 必须标 | 官方明确要求 |
| AI 生成的写实**手**、手臂、腿、背影、只露下半身、脸被遮住 | ✅ **也标** | 官方还没正式回答局部算不算，卖家论坛里有人认为全身、脸、手都算，所以从严 |
| 背景里很小的路人、镜子或屏幕里映出的人、包装图上印着的写实人像 | ✅ 标 | 只要写实又是 AI 生成的，就算 |
| 真人实拍，只用 AI 换了背景或修了图 | ❌ 不标，**但必须有实拍证据**（拍摄记录、模特授权书） | 拿不出证据，一律按 AI 人物处理 |
| 拿不准是真人还是 AI，或者算不算写实 | ✅ **标**，同时标记 `UNSURE` 交给老板 | 多标一次问题很小，漏标一次可能导致下架 |
| 插画、卡通、明显的 3D 卡通风格人物 | ❌ 不标 | 官方豁免 |
| 影视、游戏角色，或者看起来像名人、网红 | ⛔ 不在这里处理，**直接转给风控官做 IP 风险检查**（IP-CR） | 这是侵权问题，打不打标记都解决不了 |
| 人体模型（假人）、玩偶、雕塑 | ❌ 不标，在记录里注明 | 不是人 |

## 三、执行流程（每个文件都要走一遍）

```
① 定稿：裁切、压缩、加字、调色等后期处理全部做完
        ↓ （标记必须最后写入：后期处理和格式转换都可能把元数据清掉）
② 扫描：逐张看图（视频要逐个镜头抽帧看），把画面归到下面 6 类之一
        NONE 无人物 / AI_PERSON_FULL AI 写实人物 / AI_PERSON_PARTIAL AI 写实局部（手等）
        REAL_PERSON 真人（需要证据） / NON_PHOTOREAL 非写实 / CHARACTER_IP 角色或名人 → 转风控官
        拿不准就记 UNSURE，并按 AI 人物处理
        ↓
③ 打标：属于 AI_PERSON_FULL、AI_PERSON_PARTIAL 或 UNSURE 的，写入关键词（保留原有关键词，用追加方式，不能覆盖）
        ↓
④ 读回：重新读取文件，确认 XMP dc:subject 里确实有这个关键词，而且只出现一次
        ↓
⑤ 留痕：在 AI 出图记录（provenance）里加上人物扫描结果和打标结果
        ↓
⑥ 交付：只交付读回通过的文件。读回失败的，状态写 BLOCKED，不能交给文案算法师或创意美工去上传
```

## 四、怎么打标（三种方法，结果一样）

**命令行（批量处理首选，图片和视频都能用）：**
```bash
# 追加关键词（+= 是追加，不会覆盖已有的关键词；同一个文件不要重复执行，否则会写两次）
exiftool -overwrite_original -XMP-dc:Subject+=contains-synthetic-performer 图片.jpg
# 读回确认，应该看到：[XMP-dc] Subject : contains-synthetic-performer
exiftool -G1 -XMP-dc:Subject 图片.jpg
```

**Mac 预览（处理单张）**：打开图片 → ⌘+I 打开检查器 → 关键词标签页 → 点「+」→ 输入 `contains-synthetic-performer` → 回车。

**Windows**：右键文件 → 属性 → 详细信息 → **「标记」(Tags) 栏**里填关键词。注意不是「主题」(Subject) 栏。

> 在 Bot 平台里，能执行命令时用 exiftool 批量处理；不能执行命令时，把要打标的文件列表交给老板，用 Mac 预览手动加关键词，再回传确认。

## 五、和上传链路配合（自动化时尤其要注意）

1. **SP-API 或批量表格上传**：亚马逊是去你给的图片 URL 抓取文件。**托管图片的地方（图床、CDN、对象存储）不能把元数据清掉**。很多 CDN 的"图片优化"功能会删 EXIF 和 XMP，要关掉，或者上线前抽一张从 URL 下载回来读一下，确认标记还在。
2. **A+ 上传**：卖家后台的 A+ 上传页面有「AI 生成」「AI 生成人物」两个勾选框。团队口径是**两个都做**：文件里写好元数据，页面上也勾选。
3. **上传后没法在后台确认**：亚马逊会重新处理图片，从页面上下载回来的图通常已经没有标记了，卖家后台也没有显示是否识别到。所以 **⑤ 留痕记录是唯一能证明你标过的证据**，至少保存 2 年。
4. **不用在图上加可见的 "AI-generated" 字样**。主图本来就不允许有文字；副图和 A+ 由亚马逊统一显示提示。
5. **视频**：官方公告的范围写的是"图片或视频文件"。团队对视频同样写入 XMP dc:subject（exiftool 支持 MP4/MOV），并读回确认。亚马逊对视频的具体识别方式还没有更多说明，所以记录里注明"视频按图片同一规则执行，待官方补充"。

## 六、老素材补标

已经上线、含有 AI 人物的图片和视频要补标：
1. 找到原始文件 → 按第三节流程打标并读回
2. 重新上传，替换线上的版本
3. 原始文件找不到的，标记 `RETRO_MISSING_SOURCE` 交给老板，决定是重新出图还是先撤下这张图

## 八、禁止

1. ❌ 没扫描就交付，或者没读回就说"已打标"
2. ❌ 为了不显示 AI 提示，把 AI 人物说成真人，或者故意把人物画成"看起来不太写实"来逃避标记
3. ❌ 打标之后又对文件做裁切、压缩、转格式，却不重新打标、重新读回
4. ❌ 覆盖或删除文件里原有的其他关键词
5. ❌ 把 AI 人物包装成真实买家、评论者、专家、网红（这条和打不打标记无关，本来就禁止）
