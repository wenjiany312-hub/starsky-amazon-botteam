# 旺季 / 大促广告打法（seasonal_peak 先验）

> 来源：旺季广告高阶课 AD66（2025-06，13.1h）蒸馏。本文只作 **先验**：数字是课程经验值，进 `ad_strategy_brief.yaml` 前必须按本账户当前数据校准，并遵守 `formula_and_metric_contract.md` 的样本可靠性与最大有效 Bid 规则。
> 何时读：Step 2 判定阶段为 `seasonal_peak` / 用户说「备战 Prime Day / 黑五网一 / 节日季 / 旺季广告」/ S4 第 3 步「投喂打法」用户没有自己的资料时。
> ⛔ 不产出独立「作战卡」或第二份计划。所有结论只填 brief 的目标、护栏、Campaign 角色、预算与备货字段，走广告链 4.0：brief → 审核① → builder → ad_plan → 审核② → Bulk → 审核③。
> ⛔ 课中出现的刷单、直评、Woot 刷量只视为「课程提及的风险项」，不进任何方案。

## 1. 公式组（与 formula_and_metric_contract 同源，此处只列旺季用法）

```
ACOS   = CPC / (客单价 × CR)
TACOS  = 广告花费 / 总销售额
CPA    = CPC / CR
总盈利 = 自然销售额 × 毛利率 + 广告销售额 × (毛利率 − ACOS)
```

含义：自然单赚整段毛利，广告单只赚「毛利率 − ACOS」。旺季先让用户在 **利润 / 单量 / 备货** 三个目标里选一个主目标，再反推预算，映射到 brief 的 `stable_orders / rank_growth / profit / inventory_clearance / seasonal_peak`。

## 2. 备货公式（写进 brief 的库存约束，不替代 S1 财务模型）

```
备货 = 常规日销 × 常规天数 + 高峰日销 × 高峰天数 × 倍数 + 库存 × 15%
```

课中示意：`50×64 + 50×6×5 + 3500×15% = 5200 件`；倍数参考父亲节 ×3、PD ×5，**必须用本店历史校正**，没有历史就写区间并标 `course_prior`。库存覆盖不足时 Campaign 角色降为 Profit/Defense，不做 Rank 冲量。

## 3. 大促 SOP 倒排（替换档期参数即可）

1. 定大促窗口与入仓 / 秒杀提报 / 优惠券 deadline（关注平台大促资讯邮件）
2. 定产品方案：主力 / 潜力 / 长尾 / 清退（见 §4）
3. 定流量方案：本品 / 礼品 / 品类 / 关联
4. 详情页：定价、标题埋词、图 / A+ / 视频（交 S2/S3，不在广告里补）
5. 预热期按动销补货

## 4. ASIN 四级 → Campaign 角色

| 级别 | 定义 | 旺季目标 | 对应 brief 角色 |
|---|---|---|---|
| 主力 | 库存足、卖得久、销量稳 | 利润最大化：提自然单、降 CPA、高回报加预算、低回报控预算 | Profit + Defense，RES 主导 |
| 潜力 / 新贵 | 卖得短、单量上升快 | 备货拉满，核心词占高位 | Rank + Foundation |
| 长尾 | 偶尔出单、库存不多 | 最小成本换动销：捆绑、清仓页、小预算自动 | 低预算 Foundation |
| 冗余 | 款不行 / SKU 互打 / 高退货 | 清退、转仓、重新定位，不追加大促预算 | 不建角色 |

长尾成因自查（写进诊断）：流量不足 / 款不行 / SKU 互打 / 差评 / 价格 / 断货 / 季节 / 高退货。

## 5. 流量与词库

**礼品流量红绿灯**（节日档期必做）：

- 绿：节日礼品词且场景匹配（father's day gift、stress relief gift）→ 加预算精准投放
- 黄：泛礼品词（gift for her、under 25 gift）→ 控预算筛转化
- 红：弱匹配（funny gift、tech gift、handmade gift）→ 否定

**PD 词库五件套**：① 活动专用词（Prime Day / Lightning Deals）② 价格 / 促销 / 礼品词 ③ 本类目特征词 ④ 否定库：查询类（what to buy / is it worth it）+ 媒体类（reddit / youtube / blog）⑤ ASIN 流量规划表。品牌词不投放不收录。

**流量配比参考**（潜力款）：本品 80% + 品类 10% + 人群场景 10%。

## 6. PD 专属词动态竞价（相关性得分 → 出价系数，作 Bid 先验）

| 相关性 | 出价系数（× 建议竞价） | 首页 / 其余位置杠杆 | 广泛 : 精准 |
|---|---|---|---|
| 0–10 | 0.15 | 0 | 90 : 10 |
| 10–20 | 0.20 | 0 | 80 : 20 |
| 20–30 | 0.30 | 其余 20% | 70 : 30 |
| 50–60 | 0.30 | 60% | 50 : 50 |
| 70–80 | 0.30 | 100% | 30 : 70 |
| 80–90 | 0.30 | 120% | 20 : 80 |
| 90–100 | 0.30 | 160% | 10 : 90 |

70 分以上才追求首页；大促首选高相关 + 精准占比 70–90%。系数结果必须过 `formula_and_metric_contract.md` 的最大有效 Bid 护栏。

## 7. 广告架构五件套（builder 消费的角色清单）

1. 核心词精准攻坚：一活动 / 一组 / 一主推 SKU / 一词
2. 长尾词组 + 广泛：15–20 个长尾
3. 同类 ASIN：强标签 ASIN，否定主推大词防互抢
4. 关联 ASIN：留强关联，弱关联进否定
5. 自动广告：拓词 + 否定回收

## 8. 新品 12 周用词节奏（旺季前新品适用）

| 周 | 动作 |
|---|---|
| 1–2 | 贴本品属性标签（高相关 50–100） |
| 3–4 | 巩固本品核心词（含核心词、不含优质属性） |
| 5–8 | 贴关联流量（相关 30–100） |
| 9–12 | 混合核心 + 关联，拉自然单占比 |

## 9. 红绿灯诊断（大促中 / 后，交 report-analyzer 口径）

按曝光占比、点击率、转化、ACOS 相对均值分层。高曝光低点击先查主图 / 价格，不先加价硬冲。动作只有四类：提高点击 / 稳转化 / 否定 / 加预算。大促后复盘对照 brief 看自然位、TACOS、库存与分级是否打错。
