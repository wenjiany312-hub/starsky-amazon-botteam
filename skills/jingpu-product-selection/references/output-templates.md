# 输出模板

## 产品灵感池
用于用户要求"帮我找方向/给我一批选品灵感"。

| 优先级 | 产品方向 | 切入点 | 人群 | 场景 | 痛点/需求 | 待验证关键词 | 为什么可能低竞争 | 下一步 |
|---|---|---|---|---|---|---|---|---|
| P1/P2/P3 | | 人群/场景/痛点/配件/组合 | | | | | | |

输出要求：
- 一次给10-20个方向。
- 每个方向必须写明三要素，不要只列产品名。
- 标注哪些需要卖家精灵MCP验证。
- 不确定时标注"待验证"，不要编造数据。

## 单品深度报告
用于用户指定产品或要求Top方向深挖。

```markdown
# 精铺选品调研：[产品方向]

## 结论
- 建议：优先推进 / 保留观察 / 暂不建议
- 核心理由：
- 最大风险：
- 下一步动作：

## 三要素定位
- 人群：
- 场景：
- 需求/痛点：
- 低竞争切口：

## 数据验证（卖家精灵MCP）
- 核心关键词：
- 搜索量与趋势：
- ABA/关键词排名变化：
- 价格带：
- 头部评论数：
- 品牌集中度：
- 广告依赖：
- 365天新品机会：

## 竞争格局
- 前10结果精准度：
- 主要竞品/ASIN：
- 弱链接特征：
- 可差异化空间：

## 痛点与改良
- 评论/QA高频痛点：
- 可做配件/补偿件：
- 可做组合方案：

## 风险排查
- 侵权/专利：待查 / 有风险 / 暂未发现
- 认证合规：
- 供应链：
- 物流与包装：
- 季节/生命周期：

## 评分（100分制）
- 需求质量：/25
- 竞争质量：/25
- 三要素切分：/20
- 精铺适配：/15
- 风险可控：/15
- 总分：/100

评分解释：
- 80+：优先验证供应链与利润
- 65-79：保留观察，继续找差异化或更细关键词
- <65：通常Pass，除非有强供应链优势
```

## Pass说明模板
当候选不适合时，用简短明确的Pass说明。

```markdown
暂不建议推进：[产品方向]
- 主要原因：关键词太泛 / 头部评论过高 / 品牌集中 / 广告依赖强 /
  需求短期 / 侵权认证风险 / 供应链不清晰
- 证据：
- 可替代切口：从[人群/场景/痛点/配件/组合]继续细分为：
```

## 快速判断清单
用于快速判断一个产品想法是否值得深入：

```
1. 这个产品有没有具体的人群？（不是"所有人"，是某类人）
2. 这个产品有没有具体的场景？（不是"日常用"，是某个特定场景）
3. 看得懂还是看不懂？（看不懂=可能竞争低）
4. 有没有现有产品解决得不好的痛点？
5. 有没有365天内新品进入前排的类目？
6. 是否需要大量广告才能出单？（精铺要求少广告）
```
