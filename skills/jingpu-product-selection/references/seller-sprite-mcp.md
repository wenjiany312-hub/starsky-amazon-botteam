# 卖家精灵 MCP 使用规划

本 Skill 后续应优先调用卖家精灵 MCP 获取真实数据；如果 MCP 不可用，先输出待验证清单，不要编造数据。

## 典型调用意图

### 关键词需求验证
用途：验证产品词、人群词、场景词是否有需求。
需要字段：搜索量、搜索趋势、ABA排名/趋势、点击集中度、转化集中度、季节性。
判断：需求稳定或增长优先；短期暴涨需标注生命周期风险。

### 关键词竞争验证
用途：判断低竞争程度。
需要字段：搜索结果数、头部ASIN、头部评论数、评分、BSR、价格带、品牌集中度、广告位数量、自然位/广告位比例。
判断：头部评论门槛低、品牌不集中、广告依赖低、自然位有弱链接时更适合精铺。

### ASIN/竞品分析
用途：验证候选产品真实销量与竞争强度。
需要字段：月销量、销售额、价格、评分、评论数、上架时间、变体数、类目节点、BSR趋势、Buy Box、广告关键词。
判断：365天内新品能进入前排是重要正信号。

### 评论/QA分析
用途：做痛点配件、改良、组合产品。
需要字段：1-3星差评、QA高频问题、正评购买原因、差评痛点词、材质/尺寸/安装/耐用性问题。
输出：痛点→解决方案→可落地产品形态。

### 关联购买/购物篮
用途：做关联产品和隐性组合。
需要字段：Frequently Bought Together、购买后还买、购物篮商品、关联ASIN。
判断：关联不是直接照搬，必须再用三要素切细。

### 类目/榜单
用途：榜单选品、类目节点选品、FBM机会。
需要字段：BSR、新品榜、飙升榜、子类目路径、FBM/FBA占比、价格带、评论分布。

## 数据不足时的处理
- 明确标注"待MCP验证"。
- 只给假设和验证步骤，不给确定性结论。
- 不要用经验数值冒充卖家精灵数据。

## 建议评分框架
每个候选产品按100分初筛：
- 需求质量25：搜索量、趋势、生命周期、关键词精准度。
- 竞争质量25：评论门槛、品牌集中度、广告依赖、新品机会。
- 三要素切分20：人群/场景/痛点是否具体，是否避开泛需求。
- 精铺适配15：小批量、少广告、2-3个月回本可能性。
- 风险可控15：侵权、认证、供应链、物流、季节性。

评分解释：
- 80+：优先验证供应链与利润。
- 65-79：保留观察，继续找差异化或更细关键词。
- <65：通常Pass，除非有强供应链优势。
