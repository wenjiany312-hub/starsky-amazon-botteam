S5 运营接入指南

S5 做两件事：广告优化和文案优化（广告是文案的放大器，两条链一起看）。这份指南教你把数据接进来。 每一步卡住了，都可以把当前页面截图发给对话里的星空助手，它会看图告诉你下一步点哪里（截图前把密钥打码）。

所有密钥只存在你自己电脑的用户目录里，不经过任何服务器；星空不会替你上传或改后台——每一次改动都要你先确认。

0 · 先选一条路线

第一次进入 S5 运营，助手会问你走哪一条；选定后悬浮窗只显示这一条。这只是默认值，不是锁死：以后每次进 S5，助手会先用一句话确认「沿用上次路线：手动报表」，你回「沿用」就直接开始；如果它检测到你已经接入了领星，会问你要不要改用自动取数。想换随时说「换成接领星」「换成手动报表」，换了也会记住，已经配好的路线切回来不用重新配。同样的 5 步流程，不用重新学。

路线适合谁要准备什么
手动报表刚起步，或者没有 ERP什么都不用接：自己去广告后台下载表格给助手，看方案、确认、再把上传表传回后台
接 ERP 自动取数 + 飞书日报已经在用 ERP领星、赛狐、优麦云，用哪个接哪个，按官方接入指引操作；准备开放接口密钥、IP 白名单、飞书机器人和成本表

不确定就先选「手动报表」。接入状态按店铺记住，换产品或单独看全店都不用重新配置，每次只确认「本轮看全店还是这个产品」。手动表格只带成本表；ERP 路线把凭据、店铺、日报与成本表一起带完，日报可以明确说「先不要」。实际取数能力见各通道的连接测试说明。

1 · 手动报表：一轮怎么走

配置（只做一次）

  1. 对助手说 手动报表。它会在你的产品文件夹里建好放报表的地方（S5_运营板块/_投喂_广告报表/，悬浮窗里点文件夹就能打开），然后问你成本怎么给（见下面第 4 节，三选一，最轻的是说一句「毛利大概 30%」）。
  2. 助手做配置检测，全部通过会告诉你 「配置完成」，并说下一步做什么。以后每次进 S5 直接从第 2 步开始。

每一轮优化

  1. 下载报表：打开亚马逊广告后台 →「广告活动管理」→ 「批量操作」（Bulk operations）→「创建并下载电子表格」，日期选最近 7–14 天，勾选「商品推广」数据和「商品推广搜索词数据」，创建、等生成完、下载。放进上面那个文件夹，或者把文件路径发给助手。
  2. 诊断：对助手说 优化广告。助手读你的表，先拆「单量为什么变」（是曝光、点击、转化还是自然单出了问题），再结合本地广告知识库和你接的 SIF / 卖家精灵 / 西柚 / Sorftime 给每一条建议写清楚原因和依据。这一路只看广告这一侧；要连自然单一起拆，用「接领星」路线。
  3. 你审核：助手出「优化前后对比」报告（改前 → 改后、为什么、依据）。你看完回复「确认按建议改」，或点名「只改 A01、A03」；不认的直接说不要。
  4. 上传：助手生成上传表（照你下载表的语言和格式）。你回广告后台「批量操作」→ 上传这个文件。表里每一行都写明加在哪个广告活动、哪个广告组；批量上传不进去的行，就到对应广告活动的广告组里手动「添加」。上传后在「广告活动」里能看到改动，核对一下。
  5. 观察：改完 72 小时看方向、7 天看效果；同一个对象 7 天内不会被重复调整。下一轮再下载新表，助手会和上一轮对比。

文案优化（同一轮里可选）

  1. 给助手当前文案：把标题、五点、Search Terms 贴给助手，或者直接给产品链接，助手会用内置浏览器打开、读取页面上的文案和数据。
  2. 出建议：结合广告里真正出单的词、知识库和竞品情况，给出改前改后。
  3. 合规把关：改稿会对照这个产品在 S1 / S2 做过的 IP 侵权、品牌词、敏感词、受限宣称排查结果和产品 CT，撞到的词直接拦下，不会给你。没有做过 S1 / S2 排查的老品（比如你只用 S5 拉数据诊断）也会出改稿，但报告最上面会有醒目提醒：改之前你要自己确认改后没有侵权词、没有敏感词，批准文案改动时助手会请你明确回一句确认。绝对化用语（#1、best）、疗效 / 医疗宣称、抗菌、FDA 背书，以及 Q-tips 这类已知商标陷阱词，不管有没有排查记录都会指出来。想让助手先帮你排一遍，说「IP排查」。
  4. 你审核，自己到后台改：文案永远由你在卖家后台手动修改，星空不代改；改完记得核对页面。
单独下载的「搜索词报告」没有后台 ID，不能用来生成上传表——用「批量操作」那个文件就够了。

2 · ERP 路线：接入领星

接好以后：助手自动拉店铺数据，出方案；你确认后改竞价、否词、加词、改预算和广告位可以一键同步回后台（新建活动仍出上传表）。

前提

  • 用领星超级管理员账号操作；个别套餐的「开放接口」需要找领星客户经理开通。

步骤

  1. 登录领星 → 左侧菜单最下面的「设置」→「业务配置」→ 左侧「基础」里的「开放接口」（有的版本这一项在「全局」里，名字一样）。
  2. 第一次用：页面上会让你填一个邮箱（用来接收领星开放平台的通知，填常用邮箱就行），填好点「进入开放后台」，企业的 AppID 和 AppSecret 就自动生成了。以前开通过的直接跳到下一步。
  3. 看「API 账号管理」/「API 信息」：在 APP ID 和 AppSecret 两列点「查看」「复制」。没有账号的点「添加」。AppSecret 泄露了可以点「重置」，旧的立刻作废，重置后要把新的填回 txt 再说一次「接入领星」。
  4. 看「API 信息 → IP 白名单」：点「编辑」，把你这台电脑的直连出口 IP 加进去（最多 20 个）。
    不知道 IP？对助手说 查我的出口IP，它会绕开代理查准的那个。开着代理 / VPN 在网页上查到的是国外 IP，不能用。
  5. 打开安装包里的 领星密钥.txt，填好 APP ID 和 AppSecret，保存。
  6. 把这个 txt 拖进对话，说 接入领星。助手会：写进本机配置（聊天里不显示密钥）→ 测试连接 → 列出你的店铺，让你选要每天巡检哪几个。
卡住了就截图问助手：比如「开放接口在哪」「这个页面没有添加按钮」。截图前把 AppSecret 打码。

官方入口：领星开放平台文档（2026-10-17 核验：当前页面要求访问密钥，向官方客服 / 客户经理申请）。后台菜单和套餐权限以你当前账号及官方指引为准；找不到「开放接口」时向官方确认权限。取得凭据、设置白名单后，仍需本机连接测试与选店铺，不能把文档可访问当作数据已接通。

2b · ERP 路线：接入赛狐

领星、赛狐、优麦云，用哪个接哪个，按官方接入指引操作。

  1. 申请开放接口：登录赛狐，按官方业务设置与开放接口说明确认当前账号权限，必要时联系官方客户经理。
  2. 密钥 txt：向官方确认自用应用与凭据字段；若官方提供 client_id、client_secret，填入本机「赛狐密钥.txt」。字段不同先请官方确认映射，不猜字段；导入时不在聊天或日志回显。
  3. IP 白名单：按官方开放接口页面要求填写本机实际出口 IP；权限或白名单问题按官方提示排查。
  4. 连接测试：目前插件仅能保存这条通道的凭据，不能取数；保存后如实提示「凭据已存，这条通道还没接通，本轮先用手动表格」。

2c · ERP 路线：接入优麦云

官方入口：优麦云帮助中心。本次未核实到可公开使用的第三方开放接口文档，不照搬其他 ERP 的菜单和凭据字段。

  1. 申请开放接口：先向官方客服确认本账号是否支持对外开放接口、可用权限及官方接入指引；未确认时用手动表格。
  2. 密钥 txt：只保存官方实际发放的凭据文件，不猜测字段；用「接入优麦云」导入本机。
  3. IP 白名单：以官方针对该账号的要求为准，未要求时不虚构白名单配置步骤。
  4. 连接测试：本轮不开发优麦云取数；仅保存凭据，不能将文件存在说成接通。提示「凭据已存，这条通道还没接通，本轮先用手动表格」。

3 · ERP 路线的飞书日报

ERP 首次接入时一起检测，用户明确说「先不要」可以跳过，选择将被记住。

接好以后每天北京时间 9 点，手机飞书收到店铺日报：全店销售、广告花费、昨日利润、产品健康灯（🟢🟡🔴）、今日方案。

  1. 在飞书建一个群（只有你自己也行）→ 群右上角「设置」→「群机器人」→「添加机器人」→「自定义机器人」，名字随意（比如「店铺日报」）。
  2. 安全设置里建议勾「签名校验」，复制出现的密钥；再复制 Webhook 地址。
  3. 把两样填进安装包里的 飞书配置.txt，保存，拖进对话，说 接入飞书。助手会发一条测试消息到群里，收到就通了。
  4. 说 开启日报：每天 9 点自动推（电脑要开着；9 点在睡眠也没关系，中午前醒来会补推）。说 关闭日报 随时关。
Webhook 地址和签名密钥等于这个群的钥匙，别发到公开的地方。万一泄露，在机器人设置里点「重置」。

官方文档：飞书「自定义机器人使用指南」。

4 · 成本表：让「广告挣不挣钱」算得准

有了每个 SKU 的成本，助手才能算出每个产品的保本 ACOS、目标 ACOS、扣广告后利润，日报的利润和健康灯也靠它。按你愿意花的力气选一档：

档你做什么口令
A 完整用安装包里的成本表模板（或你自己的表），只填黄色列：售价、采购成本（元）、头程（元/件）、FBA 配送费、佣金率、目标利润率、姿态登记成本表 + 表的路径
B 半自动（推荐）助手从领星预填售价、每件 FBA 配送费、亚马逊实收佣金比例；领星里维护过采购价 / 头程的 SKU 也一并带出。你只补空着的黄色格生成成本表
C 最轻不想填表：告诉助手大概毛利率，先按估算算，报告和日报会标「估算」毛利大概 30%

姿态：均衡（默认）/ 保守（目标 ACOS 再收 3 个点）/ 进取（放 5 个点）/ 新品（放 10 个点，允许亏钱推量）/ 清仓（放 15 个点）。英国、欧洲站会自动扣 VAT 和数字服务费。以后从 C 换成 A / B，下一轮诊断自动变准。

5 · 接好以后每天怎么用

  1. 早上看日报：ERP 路线已接机器人时看群日报；手动表格路线从下载新表开始。红点代表需核查，不能直接当改动指令。
  2. 回到电脑，在对话里说 看今天的广告方案：助手补知识库和 SIF 依据，出优化前后对比报告。
  3. 你看完回 确认按建议改，或点名「只改 A01、A03」「把某个活动预算降到 5」。
  4. 领星能改的一键同步并核对后台操作日志；新建活动出上传表；文案出改前改后，你到后台照着改。
  5. 改完 72 小时看方向、7 天看效果；同一个对象 7 天内不会被重复调整。

6 · 常见问题

现象怎么办
连接领星报 403 / IP 不在白名单说「查我的出口IP」，把查到的 IP 加进领星白名单。家里宽带重启路由器后 IP 可能变，变了再加一次。
开着代理 / VPN领星是国内服务，星空会直连；白名单要加直连 IP，不是代理的国外 IP。
Mac 上助手读不了「下载」文件夹里的文件把文件挪到别的文件夹再给路径；或在「系统设置 → 隐私与安全性 → 文件和文件夹」里给对应应用打开「下载」权限。
飞书没收到日报电脑 9 点到中午一直关机或睡眠就不推；说「日报为什么没推」，助手会看日志告诉你原因。
我不想让它改后台不批准就不会改；每次写回前助手都会先预演给你看，你明确说同意才执行。

知识库依据与观察

方法依据自动随步骤调用；S2/S3 显示本步无库。断库提示原因并继续，缺广告手册时显示“无手册，按场景规则卡给依据”。详见安装包《内置知识库使用说明.md》和《S5报表导出与观察条件.md》。

上传前保留同对象、同层级的逐日或分窗原始报表及上传时间证据；没有观察结果不回写知识库。导出区间、每日序列与归因窗分别说明，未知口径保留待核。
