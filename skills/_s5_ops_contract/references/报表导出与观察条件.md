# S5 报表导出与 T+3 / T+7 观察条件

在用户批准并实际上传前先留好原始文件、上传时间和成功/失败回执。没有上传证据或可比观察数据，保持“缺观察结果、不回写”。

| 后台报表 | 必需字段 |
|---|---|
| Sponsored Products 广告商品报告（Advertised product） | 日期、站点/币种、活动 ID、广告组 ID、广告商品 SKU/ASIN、展示、点击、花费、归因订单与销售额及其窗口 |
| Sponsored Products 广告活动报告（Campaign）；有广告组维度的绩效导出 | 日期、活动 ID、广告组 ID（若支持）、状态、预算、展示、点击、花费、订单、销售额；导出器未提供的层级保持缺失 |
| Sponsored Products 投放报告（Targeting） | 日期、活动/组/关键词或商品投放 ID、匹配方式、竞价、展示、点击、花费、归因订单/销售额 |
| Sponsored Products 搜索词报告（Search term） | 日期、活动/组/投放 ID、顾客搜索词、匹配方式、展示、点击、花费、归因订单/销售额 |
| Sponsored Products 广告位报告（Placement） | 日期、活动 ID、广告位、展示、点击、花费、归因订单/销售额 |

导出区间是文件覆盖的开始/结束日期；每日序列是能否逐日对齐；归因窗是点击后多少天计算转化。接口字段 purchases7d、sales7d 明确为 7 天；未标窗口的 bulk 不能由文件时间跨度推断，混合口径保持待核。区间累计不能拆成每日值。

共享活动汇总不能代表单品；要比较单品，需同 SKU/ASIN 的广告商品级数据。只有活动级数据时保留共享标记，相关候选暂缓。

T0 为真实执行时间，记录时区、动作对象/ID、前后值、上传文件摘要及回执。T+3、T+7 需同对象、同层级、同币种/时区、同归因窗，提供逐日或明确分窗的修改前基线和 T0 后第 1–3 / 1–7 天报表。不要混入无关对象或把缺失日期补零。

短观察窗内转化仍可能回补：记录导出时间与归因成熟度，未成熟只做阶段观察，不能把 T+3 当作最终效果。没有这些条件则不判改动有效，不回写知识库。是否上传和何时上传由真实后台回执确认。
