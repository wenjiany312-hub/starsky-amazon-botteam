# 主题色方案库

主题色由**内容方向**决定，不是用户喜好、也不是审美问题，是**与读者建立预期一致性**。

> 财税内容用糖果色 → 读者觉得不严肃
> 用户研究内容用血红 → 读者觉得在被审判
> 选对色 = 给读者正确的阅读情绪

## 详细配色方案

每个主题给完整的 CSS 变量片段，复制即用。

### 1. 财税合规 / 政策解读（默认）

```css
:root {
  --ink: #1a1a1a;
  --ink-soft: #3a3a3a;
  --muted: #6a6a6a;
  --paper: #fdfcf7;
  --paper-warm: #f6f1e5;
  --accent: #c4382d;       /* 财税红 */
  --gold: #b8956a;          /* 金箔 */
  --gold-soft: #e8dcc4;
  --green: #2a7f5f;
  --amber: #d97706;
  --indigo: #1e3a8a;
  --danger: #b91c1c;
}
```

**适用**：跨境合规、税务、法律、政策解读、监管报告、行业白皮书

**视觉气质**：权威、克制、不冲撞，金箔点缀避免严肃过头

## 如何决定用哪个主题

### 决策树

1. **内容主要在讲合规 / 政策 / 法规？** → 财税合规（1）
2. **内容主要在讲数据 / 投放 / 算法？** → 广告数据（2）
3. **内容主要在讲品牌 / 用户 / 独立站？** → 品牌独立站（3）
4. **内容是事件警示 / 审计发现 / 紧急通报？** → 风险审计（4）
5. **内容是机会 / 增长 / 趋势？** → 增长趋势（5）
6. **内容是教程 / 培训 / 入门？** → 教程培训（6）
7. **内容是设计 / 视觉 / 品牌 manifesto？** → 创意设计（8）
8. **以上都不是 / 多主题混合？** → 行业洞察（7）

### 多 PPT / 大会综述的情况
如果一份综述包含多个嘉宾、多个主题（例如全场综述），**用主题最严肃的那一档**作为整体配色。例如有 3 位嘉宾讲广告 + 1 位讲合规，整体用财税合规色，因为合规色严肃度高。

## 修改主题色的最小成本

所有主题都遵循相同的变量名（`--ink`, `--accent`, `--gold`, `--paper`, `--paper-warm`, `--gold-soft`, `--ink-soft`, `--muted`, `--green`, `--amber`, `--indigo`, `--danger`）。

**切换主题 = 替换 :root 块**，组件 CSS 不用动。
