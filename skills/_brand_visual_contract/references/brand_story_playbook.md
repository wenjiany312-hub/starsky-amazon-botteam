# 品牌故事设计方法（适用所有站点）

品牌故事是 A+ 内容管理器里的品牌级轮播（详情页 "From the brand"），不是单品 A+。美国、英国、欧洲、日本站同一套方法，站点只决定语言与用词（英国 organised、colour）。
来源：AkoSlale 英国站品牌故事 · 收纳版 V2 上传包（2026-09 实跑，用户认可），加公开资料的模块规格。案例经验不覆盖后台当前提示。

## 一个品牌故事讲一个系列

- 产品线差异大时分开做（例：宠物版、收纳版各一份）。同一个 ASIN 不同时挂两份品牌故事；在后台按实际在售系列分组应用。
- 应用 ASIN 清单写「已知子体」，不是完整变体列表；添加时在后台核对商品名称、颜色、套装。

## 已验证的模块顺序与分工

| 顺序 | 模块 | 图片 | 后台文字 | 要点 |
|---|---|---|---|---|
| B0 | Brand Carousel Background | 电脑 1464×625 + 手机 463×625 两张 | 标题 + 一句正文 | 背景只营造氛围（暖色居家场景），不放文字、不放产品卖点；手机图单独构图，不是电脑图裁切 |
| H1 | Brand Logo and Description | Logo 315×145（透明底 PNG 最稳） | 品牌介绍一段（约 250 字符），首句可做开场 | Logo 用用户真实注册文件，不重画；介绍讲品牌为什么做这件事，点到本系列 |
| H2 | Brand Focus Image | 362×453 | 标题、正文**留空** | 标题和短句直接做进图里（例：Room for everyday life / Keep cables tucked away.），后台不再粘贴，避免重复；替代文本描述画面 |
| H3 | Brand ASIN and Store Showcase | 四宫格每格 166×182 | 后台标题一句；每格绑定 ASIN + 短标签 | 每格一张干净的单品图，标签 ≤ 20 字符左右（White cable box）；店铺入口用后台原生功能选取当前旗舰店，**不在图上画按钮**；店铺链接里的 page UUID 不当成已核实的 Store ID |
| （可选） | Brand Q&A | 无图 | 2–4 组问答 | 复用 S2 Listing 的品牌向问答 |

## 文案

- 语气温和、具体、不夸张；背景标题短（Care in Every Detail），正文一句。
- 不写功效宣称、未核实的尺寸数字、认证与排名；产品尺寸只用来约束构图（让比例对），不作为宣传文字。
- 替代文本描述图里真实看到的东西，自然带 1–2 个核心词，不堆词。

## 图片

- 场景图里的产品结构必须和实物一致（安装方式、背板、滑槽、件数）。英国站 V2 只重做了 H2：按实拍背板 / 滑槽和 SKU 尺寸图重新生成，V1 的安装结构有误作废。其余图与文案不动。
- 每张按规格导出后逐个核对像素、字节数、SHA256，写进图片清单与校验。
- 同一轮反馈只改被指出的那一块，其余锁定；每一版写修改说明，旧版保留在历史目录。

## 交付物（上传包）

从这里开始.html（按后台添加顺序：内容名称、语言、B0 → H1 → H2 → H3、应用 ASIN、替代文本，每个字段一键复制）、01_上传图片、02_文案与ASIN（后台可复制文案、后台填写 JSON、应用 ASIN 清单、四格商品绑定、图片替代文本）、图片清单与校验、使用说明、修改说明。
内容名称：品牌_站点_主题_Brand_Story_V版本_日期；语言按站点。

## 边界与状态

- 文件像素已核对 ≠ 后台已接受：未读取当前账户上传弹窗时写明；遇到裁剪或必填差异，截图后局部修改。
- 未上传、未提交审核、未发布要写清楚；后台预览、审核、上线由用户实际操作后再记录。

## 常见返工（已写进脚本检查或说明）

- 焦点图图内已有文字，后台又填一遍标题 → 留空后台标题正文。
- 四宫格图上画了「Shop now」按钮 → 删掉，入口交给后台原生。
- 同一 ASIN 挂进两份品牌故事 → 按系列拆分应用清单。
- 场景图产品结构和实物不符 → 按实拍重做该块，不整套重出。
