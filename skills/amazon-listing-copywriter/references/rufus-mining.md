# 购物助手推荐问题取样

用于有真实详情页推荐问题、用户截图或导出文本时，补充买家问题地图。问题是关注点线索，不是平台对 Listing 写法的要求，也不是本品性能证据。

## 取样与应用

1. 继承已确认竞品池，记录实际能取到的 ASIN、站点、日期、问题原文和页面/文件来源。样本数量按可得性说明，不固定要求取满若干竞品。
2. 合并近义问，保留原文与来源。频次分母是已观察样本，不称为全体买家占比。
3. 对照本品事实和 S1 限制，决定哪些能由 Title、Highlights、五点、描述或 Q&A 回答，哪些需要补证。
4. 回写买家问题、对应字段、`fact_refs`、`voc_refs`（若有）、待核项与审核状态。场景库存在时可关联其 scene_id。
5. 未取到问题时记录缺口，继续使用已有事实；不得把推测问题称为已抓取数据。

例如问题询问“是否防水”，只能据此记录防水顾虑；本品未经确认时不能写防水功能，也不能在消费者文案内写“待供应商确认”。补证要求留在审核区。

问题地图用于本地写作与审阅。不能伪造买家问答、评论或自动对外发布；变体/产品改进线索交相应阶段另审。
