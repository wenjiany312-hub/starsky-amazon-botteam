# 购物助手友好的内容表达与边界

本参考用于说明项目写作方法，不宣称某款助手已替代另一款，也不提供未经来源证实的字段权重或推荐概率。

[Amazon 的购物助手说明](https://www.aboutamazon.com/news/retail/how-to-use-amazon-rufus)提到商品信息、评论和问答等信息来源。产品功能、名称和界面会变化；需要当前功能说明时核对官方来源并记录日期。

## 可执行的方法

| 内容 | 审阅方式 |
|---|---|
| 产品身份 | 标题能让买家识别商品类型和当前变体 |
| 使用问题 | 五点/描述直接回答如何用、包含什么、适合谁 |
| 可信依据 | 参数、功能、适配边界可回到本品 fact_refs |
| 内容一致 | 标题、五点、描述与已确认图文事实不相矛盾 |
| Q&A 候选 | 真实问题来源与自编编辑问题分开，回答须有依据 |
| 改版验证 | 记录改动、观察窗口与实际可得数据；缺值为 not_measured |

不伪造评论、买家提问或平台推荐，不把本地问答候选当成已发布内容。缺账户或前台证据时，不声称已测得购物助手流量、已被推荐或固定提升排名。
