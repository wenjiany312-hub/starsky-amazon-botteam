# 安全与上下文守卫

## 凭据与网络

- 配置、`.env` 和 token 文件位于发布包之外；日志、页面、导出和错误响应不显示 secret、token、授权码或签名下载 URL。
- 本地服务只绑定 `localhost:9766`，不开放局域网或公网监听。
- 外部 URL 只允许连接器预设的 Amazon 区域主机和经过验证的报告下载目标。拒绝用户数据中提供的任意 URL、内网地址、环回地址、文件协议及跨主机携带认证头，防止 SSRF 与凭据泄漏。

## 关联与建议

- 只使用已验证的 seller、marketplace、profile、ASIN、SKU、campaign、ad group 和 native ID 映射。
- 站点、币种、时区、日期、归因窗口或来源不一致时不合并。广告组关联多个 ASIN 时，不把搜索词效果分摊给单个商品。
- 建议必须绑定生成时的事实快照与规则版本。审核前后上下文不一致则退回复核；批准不能绕过执行权限。
- 缺类目规则、禁用词、经济参数、库存或产品事实时只列缺口。SIF 信号不升级为账户事实，知识规则不升级为后台状态。
