# 亚马逊图片合规复检 v1.0

> 以卖家后台 **Product image guide**、**A+ content guidelines**、各类目的图片指南为准（2026-11-04 核对）。下面的数字和后台最新规定冲突时，以后台为准。
> 距离 policy_snapshot 超过 30 天时，先提醒老板复核一次。
> AI 人物标记单独由 `amazon-ai-person-disclosure` 负责，这里只检查有没有做。

## 一、文件规格（所有商品图）

| 项 | 要求 |
|---|---|
| 格式 | JPEG、TIFF、PNG 或不带动画的 GIF；团队默认 JPEG |
| 像素 | 最长边 500–10,000 px；≥1,000 px 才能放大查看；团队默认主副图 2000×2000 |
| 色彩 | sRGB |
| 文件名 | 不用中文和空格，避免上传出错 |

## 二、主图（任何一项不过就 FAIL）

- [ ] 纯白背景 RGB 255,255,255（检查四个角和边缘的像素）
- [ ] 产品约占画面 85% 以上
- [ ] 只有实际出售的产品和随货附件，完整展示一次
- [ ] 没有文字、Logo、水印、徽章、边框、色块
- [ ] 没有不随货附送的道具；不是插画、3D 概念图，也没有明显的 AI 风格
- [ ] 颜色和实物一致
- [ ] 默认不放人物（服装、鞋类等允许模特的类目，以类目图片指南为准）

## 三、副图

- [ ] 文字、图标只写产品事实里有的内容
- [ ] 没有：Best Seller、#1、Amazon's Choice、星级、买家评价、价格、促销、免运费、保修或退款承诺、竞品品牌或 Logo、亚马逊 Logo 或界面
- [ ] 不随货附送的道具写明 "not included"
- [ ] 尺寸图上的数字和属性一致
- [ ] 手机屏幕上文字看得清

## 四、A+、品牌故事、旗舰店

- [ ] 尺寸符合模块规格（以设计方案和对应的 A+ 技能为准）；高级 A+ 的电脑端和手机端都有
- [ ] 没有：价格、促销、有时效的用语、运费信息、保修或保证承诺、买家评价引用、出现竞品名称或 Logo 的对比、联系方式和外部网址
- [ ] 图上文字和替代文本都没有禁用词、夸大宣传
- [ ] 有写实 AI 人物的，已经打标，并提醒上传时勾选 AI 选项

## 五、视频

- [ ] 没有网址、联系方式、价格和促销、竞品
- [ ] 产品和实物一致，字幕拼写正确
- [ ] 有 AI 人物的同样要打标

## 六、真实性（所有图）

- [ ] 外形、颜色、材质、数量、配件、接口和垫图一致，没有多画或少画部件
- [ ] 没有夸大比例（尤其是尺寸、厚度、容量）
- [ ] 和文案、属性里的数量、颜色、尺寸一致
- [ ] 和设计方案一致（图位、卖点、图上文字）

## 七、输出（每个文件一条，写进出图清单）

```json
{
  "file": "products/001/S3_视觉/最终版/img_01_main.jpg",
  "slot": "main",
  "compliance_check": "PASS | FAIL",
  "issues": [{"rule": "主图-纯白背景", "where": "右下角 RGB 248,248,248", "fix": "重新抠底，背景改为 255", "type": "出图问题 | 方案问题"}],
  "checked_at": "2026-11-04T10:00:00-08:00",
  "policy_snapshot": "2026-11-04"
}
```

- **出图问题**（比如背景不纯白、像素不够）：出图工自己返修
- **方案问题**（比如方案要求主图加文字、用了竞品对比）：打回创意美工

## 八、不要做

1. ❌ 为了通过检查去改动产品本身的样子
2. ❌ 用模糊、裁掉一半的方式规避规则（比如把竞品 Logo 裁掉一半）
3. ❌ 没真正打开文件看，只凭文件名或方案就判 PASS
