## 2. 视觉出图方式（可以设置）
美工和出图工拆成两个角色，主要是为了**配不同的模型**：美工配擅长读图和创意的模型；出图工配出图模型，比如通过 MagPie 接入的 GPT 出图模型。

| 设置 | 图片 | 视频 |
|---|---|---|
| `in_team` 团队内出图 | 出图工直接读取设计方案出图 → 复检 → 交付 | 以后接入视频模型再开 |
| `outsource` 外包出图 | 美工出**投喂包** → 老板拿去 ChatGPT 网页端、即梦或外包出图 → 放进回填文件夹 → 出图工复检 | **现在默认**：美工出分镜投喂包 → 老板在即梦等平台生成 → 回填 → 出图工质检 |

- 团队默认设置：`image_mode: in_team`，`video_mode: outsource`。写在 `config/team_settings.yaml` 里
- 单个 SKU 可以单独改（台账里的 `visual_mode` 列）
- 出图工发现自己没有出图模型时，不硬出，会报告运营总监把这个 SKU 改成外包
- 状态机新增：`image_status` / `video_status` 加了 `awaiting_backfill`（等老板回填）和 `checking`（复检中）两个状态

## 3. 按角色分配模型（MagPie）
MagPie 是装在你电脑上的本地模型网关。你已经买的套餐（ChatGPT、Claude 等）、各家 API Key、本地模型都可以接进来，各个 Bot 平台统一指向它，再按角色分配模型。

| 平台 | 能不能按角色分配 | 说明 |
|---|---|---|
| OpenBot | ✅ | 每个助手对话顶部有模型选择器，你现在用的就是 `magpie/DeepSeek V4.1 F…` |
| StarSky（DSH） | 🟡 待实测 | MagPie 支持 DeepSeek Harness；每个成员能不能单独选模型，以 StarSky 设置为准 |
| Grok Bot | ❌ | Grok Bot 由平台管模型，没有模型选择器；它跑在云端，也连不到你本机的 MagPie |

- `config/team_settings.yaml` 里每个角色写的是**能力档**，比如强推理、工具主力、出图。具体用哪个模型，由买家在自己的 MagPie 里选，然后填上模型 ID
- MagPie 有图片接口和视频接口（视频接口的文档里点名了火山方舟）。出图工能不能在 OpenBot 里直接调用，**还要实测**；实测通过之前，建议先用外包出图
- 详细说明见 `docs/模型分配指南.md`
