# Mac 安装说明

> 适用：macOS 12 或更新版本。

> **装之前先确认一件事**：店铺数据由「数据底座」（星空旗舰 AI 智能广告终端）在你自己的 Mac 上读取，它和团队是两套安装、两张授权。没装底座时，选品照常，上架和运营拿不到店铺数据。底座要装在**运行 Grok Bot 桌面端、并且把命令执行路由到本机的那台电脑**上。

## 一、下载与解压

1. 打开本仓 **Releases**，下载最新的 `Starsky-BotTeam-<版本>-macos.zip`
2. 双击解压，得到 `Starsky-BotTeam-<版本>-macos` 文件夹
3. 把文件夹放到「应用程序」或你自己的工具目录（不要只放在下载文件夹里直接运行）

> 截图位：Releases 页面资产列表

## 二、申请授权

1. 双击 **申请授权.command**
2. 如果 macOS 提示「无法打开，因为无法验证开发者」：右键点这个文件 → 打开 → 再点「打开」
3. 窗口里会显示：

   ```
   产品：星空亚马逊 Bot Team 正式版
   本机申请码：XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
   ```

4. 记下 **本机申请码**，连同「要装的平台」一起发给作者

> 截图位：申请授权窗口里的本机申请码

## 三、安装

1. 收到授权码后，双击 **安装与更新.command**
2. 粘贴完整的 `SKYBT1.` 授权码，回车
3. 授权通过后，安装器会解密并生成 Grok 上传包，路径会打印在窗口里，例如：

   ```
   /Users/你的用户名/.starsky-botteam/packages/starsky-botteam_grokbot_v1.0.0-rc9_xxxxxxxx.zip
   ```

> 截图位：授权通过后的上传包路径

## 四、装进 Grok Bot

1. 把这个 zip 作为附件发给你在 Grok Bot 里的 **运营总监**
2. 对它说：

   > 把附件解压到工作目录，然后读里面的 SETUP.md，按步骤把亚马逊运营团队搭建出来。

3. 按它的提示，**你本人**设置审批规则（凡是动店铺、动钱、对外发消息的，先问你）
4. 搭好后私聊运营总监，发包里的 `docs/试跑口令.txt` 里的口令，开始第一轮选品试跑

> 截图位：Grok Bot 里上传包与搭建回执

## 五、检查新版

- 会员更新：双击 **检查新版.command**
- 也可以直接下载新版安装包，双击「安装与更新」，已保存的授权会自动校验

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示需要 Python 3.11+ | 到 python.org 下载安装 Python，再重新运行 |
| 提示「授权不属于本产品或本机」 | 申请码变了（换过电脑或重装系统），把新的申请码发给作者重新签发 |
| 提示「授权已到期」 | 已安装内容仍可用；安装新版前联系作者续费 |
| 双击 .command 没反应 | 在「终端」里输入 `bash ` 然后把文件拖进去，回车 |
