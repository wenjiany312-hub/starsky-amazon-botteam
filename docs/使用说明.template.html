接入数据工具（MCP）

最省事的做法：一份清单拖给运营总监

  1. 照 mcp/我的MCP清单_模板.md 填好（或者直接用服务商后台的截图、你在别的工具里的 MCP 配置片段），密钥能不写就不写
  2. 私聊运营总监，把文件拖进去，说：按 amazon-mcp-onboarding 把这份清单里的 MCP 接上，按默认分配给角色，先给我确认卡。
  3. 它会认出每一家、按默认表分配角色，给你一张确认卡。你回「确认」，或者「确认，另外给风控官加上 Sorftime」
  4. 接入时弹出密钥填写框，你在框里填（{SECRET_WHERE}），不要把密钥贴进聊天
  5. 每家做四层体检，最后交给你一张结果表；以后说「检测 MCP」可以随时重查

怎么知道真正配好了

层通过的证据还不能说明
① 已配置配置条目存在，密钥非空连不连得上
② 可连接能列出这个服务的工具账号有没有认证、有没有额度
③ 已认证一次只读请求成功所有接口和站点都有权限
④ 实际可调用查 1 个对象拿到真实数据整个流程都没问题

第 ④ 层会消耗服务点数，只查 1 个对象。常见卡点按顺序排查：密钥为空或填错 → 401/403（密钥值、字段名、服务是否启用）→ 点数不足或套餐到期 → 超时 / 代理 → 配置格式错误。

常见问题

Bot 每一步都停下来问我？ 回它一句「后面一口气做完，只有需要我本人操作或做不下去时再找我」。

某个角色说没有数据工具？ 看工作目录里的 config/mcp_assignment.yaml 有没有分配给它；没有就跟运营总监说「给 XX 加上 YY」。

报告里写「部分估算」？ 还没接 SP-API 费用预估或头程报价，财务管家会标明哪些数是估的，闸门 1 由你判断。

出图工出不了图？ 把出图方式改成 outsource，创意美工会出投喂包，你拿去第三方平台出图再放回来。

要更新团队包？ 把新版 zip 发给主控 Bot，说「按升级模式更新，不要删除任何角色、台账和产物」。

遇到问题怎么反馈？ 发：平台、团队包版本、哪个角色、做了什么、完整报错原文；截图遮住密钥和店铺敏感信息。
