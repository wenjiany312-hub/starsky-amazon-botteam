# 数据底座 · 只读导出接口规格 v0.1（给星空旗舰 AI 智能广告终端）

> 用途：让 Bot 团队（Grok / OpenBot / StarSky）读店铺数据，又**不碰凭据、不能写店铺**。
> 实现方：旗舰终端开发（不在团队包里写代码）。团队技能 `amazon-data-hub` 已按本规格预留调用。
> 日期：2026-11-05

## 1. 新增两个命令
```
terminal.py units                              # 列出经营单元
terminal.py export --unit <id|all> [--days 30] [--what orders,inventory,ads,finance,health,listing,returns,shipments]
                   [--out <目录> | --stdout] [--summary]
```
- 只读**本机缓存**（`refresh` 之后的数据），export 自己不发任何外部请求
- `--stdout`：把结果当 JSON 打到标准输出（Grok 在 Mac 上执行命令时，只拿得到输出，拿不到文件）
- `--summary`：只给汇总和异常（每类 ≤ 50 行），控制输出在 200KB 以内；不加时按天 / 按对象明细
- 退出码：0 正常；2 数据过期（仍输出，但 manifest 标 stale）；3 单元不存在；4 未接入

## 3. 红线（实现时必须满足）
1. 输出里**不能有**任何凭据、令牌、密钥、Refresh Token、领星 AppSecret、优麦云 `sk-ss-` 密钥、飞书地址
2. **不含买家个人信息**：姓名、地址、电话、邮箱一律不导出（订单只给汇总和 SKU 维度）
3. export / units 不能触发任何写入、推送、飞书发送
4. 每类数据都带来源和数据日期；ERP 和自接重叠时按 `overlap` 规则只算一份，并在 manifest 写明用了哪边

## 4. 验收
- `units` 列出 A_US 和接入的领星 / 优麦云单元
- `export --unit A_US --summary --stdout` 在 200KB 内，`grep -iE "secret|token|sk-ss-|refresh"` 无命中
- 断网后执行仍能输出（只读缓存），数据过期时退出码 2
