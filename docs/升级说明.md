# 团队包升级说明（OpenBot）

> 给 OpenBot 里的运营总监看。升级由安装器完成，你只负责把助手和文件对齐到新版本。

## 安装器做了什么
- 旧 `{KIT}` 改名为 `kit_<旧版本>_备份`（原样保留，不删）
- 新团队包写进 `{KIT}`
- `{WORK}`（台账、产品文件、`config/`、报告）**一个字都没动**

## 你只做四件事
1. **换提示词**：按 `{KIT}/agents/<角色 id>.md` 的「系统提示词」全文，逐条更新 11 个助手的指令。用助手设置 →「指令」→「编辑指令」整段替换，前面加一句「这是你更新后的长期工作说明，替换之前的版本」
2. **补技能**：`openbot.list_local_skills` 看新增技能在不在；不在就按 `{KIT}/SETUP.md` 第 5 步装，然后按每个助手档案头部的 `skills` 调开关（`openbot.set_skill_enabled`）
3. **核对本地 MCP**：跑一次 `bash {KIT}/mcp/local/install_local.sh`（已装的不会重装），看 4 个 MCP 还通不通；不通常见原因是目录没对，按脚本最后打印的参数重填
4. **核对权限**：每个助手的 助手设置 →「权限」→「访问权限」仍应是「先询问」；`{KIT}`、`{WORK}` 仍在文件夹列表里

## 不要做
- 不要删助手、不要新建同名助手、不要清空助手记忆
- 不要动 `{WORK}/config/`、台账、products 下的任何文件
- 不要为了验证去调用卖家精灵等按次扣费的数据工具，只看连没连上

## 交回执
逐个列出 11 个助手的：版本标记（`agents/<id>.md` 末尾那行 `<!-- starsky-botteam … -->`）、技能开关、本地 MCP 连通情况、访问权限档位。有哪一项没对齐，写清楚卡在哪。
