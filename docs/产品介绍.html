一、它解决什么问题

一个人做亚马逊，真正的瓶颈不是不会，而是管不过来：

选品靠感觉没有系统的市场穿透和竞争难度评估，赌的成分大
风控没人盯侵权、类目限制、账户健康出事就是大事，一个人很容易漏
利润算不清FBM / FBA 双算、头程、广告预算，每次都要重新理一遍
内容做不快词库、文案、主副图、A+，一个品一套，堆人也不够
数据看不到店铺数据散在后台各处，等想起来看已经晚了

这套产品把上面每一件事交给一个专门的 AI 角色，角色之间按状态机交接、互相检查；动钱和动店铺的每一步都停下来等你确认。旗舰版再配一个装在你自己电脑上的「星空广告终端」，把店铺数据接到本地，每天自动出简报和巡检。

三、团队是什么：11 个角色 + 1 个老板

运营总监 调度项目经理：派活、查规矩、到闸门停下来等老板；每天发台账日报。不做业务判断
选品侦察员 执行先和你聊清方向（站点、价位、精铺还是纵深、目标毛利率），再拉数据出市场报告
风控官 把关商标专利、受限类目、账户健康；一票否决，只有老板能改判
仓管物流 执行1688 找厂、量尺寸算头程、管 FBA 货件
财务管家 执行FBM / FBA 双算、保本 ACoS、广告预算上限
文案算法师 执行词库、标题五点、上架资料包、文案维护
创意美工 执行主副图、A+ / 品牌故事、旗舰店、视频分镜设计
出图工 执行按设计出图，三项复检：真实性、图片规范、AI 人物标记
质检官 把关上架前检查：页面和实物对不对得上
广告优化师 执行新品广告架构、调整建议、Bulk 候选表
复盘分析师 执行第 3 / 7 / 14 / 30 天复盘，经验写回知识库

七、旗舰版：星空广告终端（装在你自己电脑上）

旗舰安装包装完团队后，安装器自动把广告终端装到本机（程序在 ~/.starsky-botteam/ads-terminal，数据在 ~/星空广告数据），并在桌面生成三个图标：

启动星空广告终端双击打开综合看板；没接入时自动进接入向导
星空每日经营简报双击直接看今天的经营：销售、毛利、广告、退货、异常提醒（网页 + 可发飞书）
停止星空广告终端一键停掉本机服务

接入向导：三步接上你的店铺

  1. 接 ERP：领星 OpenAPI 或优麦云（可多店多站）
  2. 接店铺 API：Amazon Ads API（只读报表）+ SP-API（订单、库存、Listing）
  3. 维护成本表：本地 Excel 填采购价和头程，利润按你自己的账算

安全边界

  • 数据全部留在你自己电脑上，不经过任何云端服务器
  • 终端全程只读；推送只在你本人在审核报告里输入「确认推送」后执行，团队不能代确认
  • 密钥只存在本机终端里，永不进入对话或工作目录

九、怎么装（三步）

  1. 下载安装包（按你的电脑系统选 macOS / Windows），解压后双击「申请授权」，把显示的 32 位本机申请码 发给作者，注明要装的平台和版本
  2. 拿到授权码后，双击「安装与更新」粘贴：装 Grok Bot 得到带水印的上传包 zip（发给云端的运营总监搭建）；装 OpenBot 直接写进本机目录并打印搭建口令；旗舰版另自动装好本机广告终端
  3. 搭好后私聊运营总监开始第一轮试跑；旗舰版双击桌面「启动星空广告终端」接店铺数据

以后怎么更新

办法怎么做说明
① 检查新版
（推荐）		双击「检查新版」安装器自己去 GitHub 取最新版，下载、校验、安装，不用手动下载。团队和本机广告终端一起更新，已接入的店铺数据和配置保留。只对会员版有效
② 下载新包到发行页下载新版 zip → 解压 → 双击「安装与更新」适合固定版本试用。注意：老安装包里的「安装与更新」只重装它自己那一版，不会去拉新版——要新版必须先下载新安装包

更新后只有 Grok Bot 用户要多做一步：把新上传包发给云端的运营总监，并让它把 11 个助手的系统提示词全部重发一遍——新版的行为改动都在提示词里。OpenBot 用户按安装器打印的口令对齐即可，work/ 不会被改动。
