> 版本：2026-11-10（v2：设备码 + 云电脑码） · 适用：星空亚马逊 Bot Team 全部版本（预发行、正式版）

## 一、一份授权管什么
一个授权编号 = 一个席位：**一台本地电脑（设备码）+ 一个正在使用的 Grok 账号（云电脑码）+ 服务期内的更新**。

| 项 | 约定 |
|---|---|
| 换电脑登录 | 同一个 Grok 账号在 Mac、Windows、手机上登录使用都可以，不用重新授权 |
| 同时使用 | 同一时间只能装在**一个** Grok 账号上；要同时用多个账号，每个账号一份授权 |
| 换绑 | Grok 账号被封、换新账号、本地电脑更换时，凭授权编号 + 设备码申请换绑。**服务期内含 2 次免费换绑，超出后的换绑请联系作者** |
| 不扣次数 | Grok 自己重建了云电脑、你的 Grok 账号没变 |
| 换绑以后 | 服务期不变；旧账号上已装的内容不删除，但不再收到更新 |

## 二、更新
- **会员更新**：会员期内可以用「检查新版」拿新版本，到期后已装内容继续能用，不再提供新版
- **固定版本试用**：只能安装签发时的版本
- 更新只发给登记过的授权；违反本条款的授权停止更新

## 三、不允许
1. 把云电脑里的 kit、角色提示词、技能、知识库**转给他人、转售、公开发布**，或装进未登记的 Grok 账号；用换绑名义把授权转给他人
2. 删除或篡改水印（`license/watermark.txt` 和每个角色说明末尾的授权编号）
3. 拿本产品的内容改名、拆分后当作自己的产品出售

## 四、水印
每个安装包都写有本授权的编号。发现外流的副本，按编号追查到对应授权，**停止该授权的更新与服务，不退费**。

## 五、费用与责任
- 授权码签出后不退款（内容已解密交付）；签码前可退
- Grok Bot 的套餐和用量由使用者自己的账号承担，额度用完需自行补充；第三方数据工具（SIF、Sorftime、西柚、卖家精灵等）的账号和费用由使用者自理
- 本产品只做分析、方案和资料准备；**所有改店铺的操作（上架、改价、广告）都由使用者本人确认后执行**，经营结果由使用者自己负责
- 店铺密钥只填在使用者自己电脑的数据底座里，不发给任何 Bot，也不发给作者

## 六、技术边界（如实说明）
授权锁的是**下载、安装和更新**。装进 Grok 以后，提示词是明文，技术上无法防止复制，所以靠水印追查和本条款约束。
