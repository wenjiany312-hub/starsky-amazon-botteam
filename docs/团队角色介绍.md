# 星空亚马逊 Bot Team · 角色介绍

> 11 个 AI 角色 + 1 个老板，覆盖亚马逊美国站 FBA + FBM 从选品到复盘的全流程。
> 一句话：**AI 干活，AI 互相检查，钱和风险由人拍板。**

---

## 一、全景：11 个角色，分成 3 类

| 类别 | 角色 | 一句话 |
|---|---|---|
| 🧭 **调度** | 运营总监 | 项目经理：派活、查规矩、到闸门停下来等老板 |
| 🛠 **执行** | 选品侦察员选品 | 找有市场的品 |
| | 仓管物流货源与仓储 | 找货、量尺寸、管物流和 FBA 库存 |
| | 财务管家利润 | 算钱：能不能赚、走 FBM 还是 FBA、广告最多花多少 |
| | 文案算法师文案与上架 | 写标题五点、上架、维护文案算法师 |
| | 创意美工 | 所有视觉设计：主副图、普通 / 高级 A+、品牌故事、旗舰店、视频分镜 |
| | 出图工 | 按设计出图，三项复检（真实性、图片规范、AI 人物标记）；视频只做质检 |
| | 广告优化师广告 | 新品广告、调整、出 Bulk 表格 |
| 🛡 **把关** | 风控官 | 侵权、合规、账户健康，有一票否决权 |
| | 质检官质检 | 上架前检查：页面和实物对不对得上 |
| | 复盘分析师复盘 | 判断放量还是下架，并把经验写回知识库 |
| 👤 **拍板** | 老板（你） | 7 道闸门：选品、上架、广告预算、转 FBA、补货、清仓、下架 |

## 二、流程里谁在什么时候出场

```
老板下指令 → 运营总监
  ① 选品段   选品侦察员选品 → 风控官风控 → 仓管物流货源 → 财务管家利润 → 🔒老板确认选品
  ② 内容段   文案算法师写文案 ∥ 创意美工设计 → 出图工出图 → 质检官质检 → 风控官上架前风控 → 预检 → 🔒老板抽检
  ③ 上架段   文案算法师出上架资料包 → 老板后台创建 → 可售（∥ 创意美工做 A+）
  ④ 广告段   🔒老板确认预算 → 广告优化师开新品广告
  ⑤ 复盘段   复盘分析师第 3/7/14/30 天复盘 → 放量 / 优化 / 暂停 / 转 FBA / 补货 / 清仓 / 🔒下架
  全程       风控官每天盯账户健康，碰到红线全店暂停
```

## 三、每个角色详细介绍

### 🧭 运营总监
- **干什么**：把老板的一句话整理成任务单；按 SKU 状态表派活给对应角色；收到结果后检查 7 项规矩（是不是该你干、有没有跳步、字段齐不齐、有没有证据、版本对不对、有没有被暂停挡住、有没有越权）；到闸门把同一批的品合成一张审批卡交给老板；每天发台账日报。
- **权限**：只能改台账里的流程字段，**不能调任何店铺 API**，也不能写闸门字段。
- **为什么这么设**：多个 AI 协作，最容易出的问题是乱跑、跳步、互相覆盖。运营总监只管流程、不懂业务，所以不会"既当裁判又当运动员"。它不判断品好不好，角色之间有分歧就摆给老板看。

### 🛠 选品侦察员选品分析师
- **干什么**：按任务单从市场数据里找候选品，给出需求、竞争、季节性和履约倾向（FBM 测款或直接 FBA），并写下"需要风控重点查"的提示。开工前先读知识库里的淘汰黑名单和复盘经验。
- **权限**：只读市场数据，只写自己那几列。
- **为什么这么设**：选品只回答"有没有市场"。侵权、货源、利润交给专门的角色，否则一个 AI 什么都管，什么都做不深。同时给它设了**数据调用上限和交付时限**，防止它无限制地查数据、烧积分。

### 🛡 风控官
- **干什么**：
  - G1 选品后：查商标、专利、版权、受限类目、危险品、美国认证（CPC、FCC、EPA 等）、FBA 禁运
  - G2 上架前：查文案里的品牌词和违禁词、主图合规、AI 人物标记记录
  - G3 每天：盯账户健康（ODR、迟发率、IP 投诉等），碰到红线就**全店暂停新上架和新广告**
- **权限**：只读，**一票否决**。它判淘汰，运营总监不能推翻，只有老板能改判。
- **为什么这么设**：铺货最大的风险不是技术，而是**侵权和账户被封**。店铺只有一个，所以风控必须独立。选品的人自己查自己，很容易放水。它的原则是"拿不准就从严"，查不到的不判通过，交给老板决定。

### 🛠 仓管物流货源与仓储
- **干什么**：找 1688 供应商（至少 3 家），给出阶梯价、起订量、交期、**包装后**的尺寸重量、HTS 编码和关税；FBM 负责备货天数和运费模板；FBA 负责发货计划、入仓跟踪、每日库存和库龄巡检，以及补货、清仓预警。
- **权限**：只读，执行计划要等老板批准；货件由老板在后台创建。
- **为什么这么设**：财务管家算利润全靠它给的数字，数字错了后面全错。所以每个数字都要标来源等级（已确认 / 页面信号 / 估算），过闸门 1 之前不能有"估算"。另外，美国小额包裹免税已经取消，国内直发也必须算关税。

### 🛠 财务管家利润分析师
- **干什么**：每个品都按 **FBM 和 FBA 各算一遍**，给出净利率、保本 ACoS、价格底线，以及履约建议（FBM 测款 / 直接 FBA / 两种都做 / 只能 FBM / 不做）；算出新品广告预算上限；测算转 FBA 要压多少钱、多久回本；复盘时提供实际利润。
- **权限**：只读。
- **为什么这么设**：广告"最多能亏多少"、FBA"最多压多少钱"，都需要一个统一的底线。广告优化师和仓管物流只能在财务管家给的上限以内动作，费率一律以亚马逊最新数据为准。

### 🛠 文案算法师文案与上架
- **干什么**：做关键词和文案（标题、五点、描述、搜索词、属性）、上架预检、出上架资料包、跟到可售；以后负责老品文案优化、FBA 和 FBM 双 SKU、清仓改价。
- **权限**：现在新建 Listing 由老板在后台创建；改老品文案也要先给老板看新旧对比。
- **为什么这么设**：文案决定能不能被搜到、能不能过审。它和图片同时做，交给质检官和风控官两道检查；没有老板批准和亚马逊回执，就不能写"已上架"。

### 🛠 创意美工
- **干什么**：设计主副图（7 图套图）、普通 A+、高级 A+、品牌故事、品牌旗舰店、视频分镜；交设计方案 + 出图 Prompt。没有出图模型或要外包时，交「出图投喂包」，老板拿去 ChatGPT 网页端、即梦或外包出图。
- **权限**：只设计，不出图、不上传。A+、品牌故事、旗舰店只做有品牌备案的品。
- **为什么这么设**：专业设计和执行出图分开，可以给美工配擅长读图和创意的模型，给出图工配出图模型；没有出图模型的用户也能用（投喂包外包出图）。

### 🛠 出图工
- **干什么**：按美工的方案出图；不管是自己出的还是外包回填的，每张图都做三项复检：真实性、亚马逊图片规范、AI 人物标记（写实 AI 人物写入 contains-synthetic-performer 并读回）。视频目前由老板在即梦等平台生成，回填后由它质检。
- **权限**：不改设计、不上传，只交 READY 的文件。
- **为什么这么设**：亚马逊要求 AI 人物必须标记，漏标可能导致图片被删甚至 ASIN 被屏蔽；复检集中在一个角色，标准统一。

### 🛡 质检官质检
- **干什么**：上架前做最后一遍一致性检查（4 组 17 项）：文案和事实、图片和文案、AI 人物标记记录、买家体验。只回答一个问题：**买家收到的货，和页面上看到的是不是同一个东西？**
- **权限**：只能打回，不改内容。
- **为什么这么设**：写的人查不出自己的错，所以质检必须独立，不能让文案角色兼任。不一致是退货和差评的主要来源。

### 🛠 广告优化师广告投手
- **干什么**：新品广告方案（自动 + 核心词精准 + 拓展词）、出 Bulk 表格并校验、按复盘结论调整、断货时紧急暂停。
- **权限**：现在出表格，由老板上传；预算不能超过财务管家的上限和老板批准的数字。
- **为什么这么设**：广告是 Listing 的放大器，投的词来自已经审过的文案，不另起一套。"花钱"必须有底线、有证据、有回执：加预算一律重新过闸门，没有处理报告不能写"已上线"。

### 🛡 复盘分析师
- **干什么**：上架后第 3、7、14、30 天复盘；按"曝光 → 点击 → 转化 → ACoS → 利润"逐层找问题；给出放量、优化、暂停、转 FBA、补货、清仓、下架等结论；**把经验写回知识库**。
- **权限**：只读，只出建议，执行交回对应角色。
- **为什么这么设**：没有复盘，整个流程就只是"流水线"；有了复盘才能形成闭环。数据不够就不下结论（第 7 天不能判下架），同一条经验有 3 个以上 SKU 验证过才算"规则"。下一轮选品侦察员选品、广告优化师投放都会读这些经验，团队越用越准。

## 四、为什么这样设计：7 条原则

| # | 原则 | 落在哪里 |
|---|---|---|
| 1 | **干活和检查分开** | 执行 7 个、把关 3 个；写的人不查自己（质检官、风控官独立） |
| 2 | **能只读就只读** | 11 个角色里大部分只读；店铺写操作都要经过闸门 |
| 3 | **钱和风险由人拍板** | 7 道闸门只认老板本人；涉及资金的闸门任何时候都要人工确认 |
| 4 | **每一列只有一个人能写** | 台账按角色划分写入权，防止互相覆盖 |
| 5 | **有证据才算数** | 每个结论都要附文件；没有亚马逊回执，不能写"已上架""已上线" |
| 6 | **对人说人话** | 对话里只发中文交付卡，JSON 和长清单放文件；运营总监把所有角色的结果重排后再给老板（`workflow/输出排版规范.md`） |
| 7 | **越跑越准** | 风控官的淘汰原因和复盘分析师的复盘经验写回知识库，喂给下一轮选品和广告 |

## 五、自动化怎么一步步放开

| 等级 | 老板要做什么 | 什么时候用 |
|---|---|---|
| L1 | 每一步都确认 | 第一次跑（现在） |
| L2 | 只在闸门确认 | L1 稳定跑 2–4 周后 |
| L3 | 选品、上架按规则自动放行；只确认预算和资金 | L2 稳定后 |

无论哪个等级，**转 FBA、补货、清仓这类动钱的决定都要老板本人确认**，风控官的全店暂停也只有老板能解除。
