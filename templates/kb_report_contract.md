# 必需 Markdown 的知识库依据生成契约

人工/助手撰写的 required_artifacts 中 `_md` 报告，使用 `scripts/kb_report_contract.py` 的 `render_authored_report`，在保存最终报告、计算哈希之前调用；引用来自本轮实际回包及已登记用途，不补造卡号或来源。本步计划无库且无复用时直接生成；实际断库无引用时保留失败原因和顶部配置提示；实际引用时缺依据小节即失败。后续 `verify_kb_evidence` 仍校验完整计划、失败调用、实际标题、卡片、用途和回包，格式写入不等同证据通过。

CT、成本、阶段总报告使用其原生生成器写依据并封哈希，禁止事后手加内容或重写旧哈希。确定性 `ruler_md` 是唯一例外：仍生成且仍校验哈希；第8步知识库引用由 IP 报告及竞争与IP结论承担。

只认最后一个 `## 知识库依据` 小节（可带 `（第 N 步）` 后缀），到下一个同级或更高级标题为止；正文提及这四个字不算小节。新增 `_md` 角色必须先登记生成契约；运行 `scripts/selftest_contracts.py --home 当前插件目录` 自检，不能把未知角色塞进例外名单。
