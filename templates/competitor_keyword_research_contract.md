# 沙龙第二版｜竞品确认与关键词数据口径契约

版本：1.0（2026-07-22）

## 1. 两道人审/确认门

### Gate A：竞品池

- 默认按同类目 BSR 1–30 / 31–60 / 61–100 生成 6/6/5 个相关候选，官方新品榜 3 个；不足则写实际数与缺额。同父体不凑数，补位保留来源段与理由，新品榜不可得才用带来源的上架日期回退。
- 每行至少包含 ASIN、图片、标题、类目、价格、销量/BSR信号、上架时间、Top 流量词、AI 建议与理由、人工决定、来源段、是否补位/理由、价格带状态与来源文件hash。
- 本轮候选表由用户确认并绑定 review_sha256；旧20池确认不能自动成为新分层确认，缺额需范围确认。演示自动选择只用于分析，不允许绕过生产入库。
- 目标 ASIN 自身可作为研究锚点，但必须标 `benchmark/target`，不能误当独立竞品样本。

### Gate B：分类口径

在补全 CPC/CVR/SPR/流量结构前，先展示产品词根、产品词/属性词、二级/三级分类和代表词。生产模式允许用户修订；演示模式沿默认分类续跑并留修订入口。

## 2. 共同覆盖

每个词保留：

```yaml
competitor_coverage_count: 0
competitor_asins: []
confirmed_competitor_count: 0
coverage_ratio: 0.0
```

默认共同覆盖阈值是建议值，不是硬规则：

- 确认竞品 ≥10：可从覆盖 5 个起看。
- 确认竞品 5–9：可从覆盖 3 个起看。
- 确认竞品 <5：不设“覆盖 5”硬门槛，按 coverage_ratio 与相关性解释。
- 低覆盖但高相关、高搜索或明确长尾意图的词进入机会池，不机械删除。

## 3. 指标字典与禁错

| 指标 | 正确口径 | 禁止误映射 |
|---|---|---|
| keyword CVR | click-to-purchase conversion rate | SellerSprite purchaseRate、Top3 转化集中度 |
| Top3 conversion share | 前三点击商品的转化集中结构 | 关键词 CVR |
| CPC | bid；缺失时 bidMin/bidMax 中点 | 无来源猜测值 |
| CPR8/SPR | 对应 SPR/CPR 字段 | traffic_keyword.sprt |
| CPA | `CPC / CVR` | CVR 为空或 0 时强算 |

## 4. CPA 公式

```text
预计 CPA = CPC / CVR
```

CVR 使用小数，例如 12% = 0.12。CPC/CVR 任一缺失或 CVR=0 时 CPA 留空并写缺失原因。

## 5. 来源日志

最终词库必须带 `data_source_log`：工具/文件、参数摘要、时间窗口、返回量、是否截断、缺失字段、失败与回退。API 凭据不得落盘。

## 6. 数量守恒

```text
原始行数
= 保留行数 + 合并重复行数 + 排除行数 + 待确认行数
```

六维标签、Listing 分池、广告分池与否定词必须可回溯到原始词和排除理由。

## 7. acceptance_checks

- [ ] 候选、确认、排除数量守恒。
- [ ] 每个词含覆盖数与 ASIN 列表。
- [ ] 指标未发生 CVR/集中度/SPR 静默误映射。
- [ ] CPA 可复算，缺数不伪造。
- [ ] 来源日志含时间、数量、截断和失败。
- [ ] 分类口径有确认或 demo_default 记录。
